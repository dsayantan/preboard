Time allowed: 3 hours (180 minutes). Section A questions have four options with exactly one correct; Section B answers are integers (possibly negative) typed in, with any rounding stated in the question.

How scoring works

  • +4 for each correct answer, −1 for each wrong answer, 0 for a question not answered — in both sections, as in the current NTA pattern.
  • Only saved responses count. A question answered and marked for review is evaluated; one marked for review without an answer is not.
  • The clock keeps running if you leave the page; reopening the test resumes it. At zero the test submits itself.
  • Your answers and score stay in this browser. Retake on the result page clears them.
