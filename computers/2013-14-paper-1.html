Q1Boolean Algebra[2]

State Idempotent law of Boolean Algebra and prove using truth table.

Answer

Idempotent law: a variable ORed or ANDed with itself gives the variable itself:

(a) \(A + A = A\)     (b) \(A \cdot A = A\)

Proof by truth table

AA + AA·A
000
111

The columns \(A+A\) and \(A\cdot A\) are identical to the column \(A\) in every row, hence \(A+A=A\) and \(A\cdot A=A\).

Concepts to recall

  • Idempotence: \(A+A=A\), \(A\cdot A=A\).
  • A law is proved by a truth table when the two sides have identical columns for every input combination.

Q3Boolean Algebra[2]

Simplify algebraically \(\;\overline{[(\bar p+q)\cdot(\bar q+r)]}+(\bar p+r)\)

Answer

\[ \begin{aligned} F &= \overline{(\bar p+q)(\bar q+r)}+\bar p+r\\ &= \overline{(\bar p+q)}+\overline{(\bar q+r)}+\bar p+r &&\text{(De Morgan)}\\ &= p\bar q+q\bar r+\bar p+r &&\text{(De Morgan, involution)}\\ &= (\bar p+p\bar q)+(r+q\bar r)&&\text{(regrouping)}\\ &= (\bar p+\bar q)+(r+q) &&(x'+xy = x'+y,\; x+x'y=x+y)\\ &= \bar p+(\bar q+q)+r = \bar p+1+r &&(\bar q+q=1)\\ &= 1 \end{aligned}\]

\(F = 1\) — the expression is a tautology (true for every p, q, r).

Concepts to recall

  • De Morgan: \((xy)'=x'+y'\), \((x+y)'=x'y'\).
  • Redundant literal: \(x'+xy=x'+y\).
  • Complement law \(x+x'=1\); \(1+x=1\).

Q5Boolean Algebra[2]

Given F(P,Q,R) = (P+Q) . (Q+R). Convert it to its canonical POS form using Boolean Algebra.

Answer

Each sum term must contain all three variables; supply the missing one with \(XX'=0\):

\[\begin{aligned} P+Q &= P+Q+RR' = (P+Q+R)(P+Q+R')\\ Q+R &= Q+R+PP' = (P+Q+R)(P'+Q+R) \end{aligned}\]

\(F=(P+Q+R)(P+Q+R')(P+Q+R)(P'+Q+R)\). Removing the repeated factor (idempotence, \(X\cdot X=X\)):

\(F(P,Q,R)=(P+Q+R)\,(P+Q+R')\,(P'+Q+R) = \prod(0,1,4)\)

Concepts to recall

  • Canonical POS: every maxterm contains every variable once.
  • Missing variable X: add \(XX'\) and use \(A+BC=(A+B)(A+C)\).
  • Maxterm: variable 0 → uncomplemented, 1 → complemented.
Q6Arrays (address calculation)[2]

A two dimentional array defined as DATA [30][40] requires 4 bytes of storage space for each element. If the array is stored in Row-major-Order, determine the address of DATA[10][10], given the base address as 1234.

Answer

Taking the Java/C convention of the declaration, indices start at 0 (so the base address 1234 is the address of DATA[0][0]); number of columns \(N=40\), \(W=4\).

\[\text{Address}(\text{DATA}[I][J]) = B + W\,[\,N(I-L_r)+(J-L_c)\,]\]

\[= 1234 + 4\,[\,40(10-0)+(10-0)\,] = 1234 + 4\times 410 = 1234+1640\]

Address of DATA[10][10] = 2874

If the rows and columns were numbered from 1 instead, the same formula gives \(1234+4[40(9)+9] = 2710\). State the lower bounds you assume.

Concepts to recall

  • Row-major: \(B + W[N(I-L_r)+(J-L_c)]\), N = number of columns.
  • Column-major: \(B + W[(I-L_r)+M(J-L_c)]\), M = number of rows.
  • Base address = address of the first element.
Q7Boolean Algebra[2]

Find the Complement of A′B′ + A′ + A.B

Answer

Simplify first: \(A'B'+A'=A'\) (absorption), so \(F=A'+AB=A'+B\) (redundant literal).

\[F' = (A'+B)' = A''\cdot B' = A\,B'\]

Check by De Morgan directly: \((A'B'+A'+AB)'=(A+B)\cdot A\cdot(A'+B') = A(A'+B') = AA'+AB' = AB'\).

Complement = \(A\cdot B'\)

Concepts to recall

  • De Morgan: complement each literal and swap + and \(\cdot\).
  • Absorption \(X+XY=X\); \(X'+XY=X'+Y\).
Q8Computer Hardware (NAND as universal gate)[2]

Draw circuit of the following expression using NAND gates only.

AB′ + [A′( B + C′ )]

Answer

Expand into sum-of-products: \(F = AB' + A'B + A'C'\).

A two-level AND-OR circuit becomes NAND-NAND: \(F = \overline{\overline{AB'}\cdot\overline{A'B}\cdot\overline{A'C'}}\) (double complement and De Morgan). The complements \(A', B', C'\) are produced by NAND gates with their inputs tied together \((\overline{X\cdot X} = X')\).

Gates: 3 NAND inverters + 3 two-input NANDs + 1 three-input NAND.

Concepts to recall

  • SOP → NAND-NAND: replace both levels of AND-OR by NAND.
  • NOT from NAND: tie the inputs, \((XX)'=X'\).
  • \(\overline{\overline{P}\,\overline{Q}} = P+Q\).
Q10Data Structures (binary trees)[2]

Define a Binary Search Tree

Answer

A binary search tree is a binary tree in which, for every node,

  • every value in its left subtree is less than the node's value, and
  • every value in its right subtree is greater than the node's value;
  • the left and right subtrees are themselves binary search trees.

Example:

Its inorder traversal (20 30 40 50 60 70 80) is in ascending order.

Concepts to recall

  • Binary tree: each node has at most two children (left, right).
  • BST ordering: left < root < right at every node.
  • Inorder traversal of a BST gives sorted order.
Q11Inheritance, Interfaces and Polymorphism[4]

Explain the use of super and this keyword in terms of Inheritance.

Answer

this — a reference to the current object.

  • Separates an instance variable from a parameter/local of the same name: this.roll = roll;
  • Calls another constructor of the same class: this(…); or passes the current object as an argument.

super — a reference to the superclass part of the current object.

  • super(…) calls the superclass constructor; it must be the first statement of the subclass constructor.
  • super.method() calls the superclass version of a method the subclass has overridden; super.x reaches a superclass variable hidden by a subclass variable of the same name.

Example:

class Person {
    protected String name;
    Person(String name) {
        // 'this' separates the field from the parameter
        this.name = name;
    }
    void show() {
        System.out.println("Name : " + name);
    }
}

class Student extends Person {
    int roll;
    Student(String name, int roll) {
        // calls the superclass constructor (must be first)
        super(name);
        // this.roll is the field, roll the parameter
        this.roll = roll;
    }
    void show() {                  // overrides Person.show()
        // calls the overridden superclass version
        super.show();
        System.out.println("Roll : " + this.roll);
    }
}

new Student("Ujaan", 12).show(); prints

Name : Ujaan
Roll : 12

Concepts to recall

  • this → current object; super → its superclass part.
  • super(...) must be the first statement in a constructor.
  • Overriding: same signature in the subclass; super.m() reaches the hidden version.

Q16(a)Computer Hardware (adders)[4]

16 a) Using two half adder and an OR gate construct a full adder.

Answer

Half adder: \(S = a\oplus b\), \(C = ab\). Full adder: \(\text{SUM} = A\oplus B\oplus C\), \(\text{CARRY} = AB + C(A\oplus B)\).

Q16(b)Computer Hardware (universal gates)[6]

b) Show how NAND gates can be used to simulate function of NOT, AND & OR gates.

Answer

NOT: tie both inputs together: \(\overline{A\cdot A} = A'\).

AND: NAND followed by a NAND inverter: \(\overline{\overline{AB}} = AB\).

OR: invert each input with a NAND, then NAND them: \(\overline{A'\cdot B'} = A'' + B'' = A+B\) (De Morgan).

Since NOT, AND and OR can all be built from NAND alone, NAND is a universal gate.

Concepts to recall

  • NAND: \((AB)'\).
  • De Morgan: \((A'B')' = A+B\).
  • Universal gate: every Boolean function can be built from it alone.

Q17Objects and classes[10]

Two different timings are added as :-
Time1 - 6hrs  35 mins
Time2  3hrs  45 mins
Sum   10hrs  20 mins

To find the solution of above question a class time is declared:

Data members:
hrs,min : integer to store hours and minuties

Methods :
time( ) : Consturctor to assign 0 to hrs and min
void gettime( int h, int m ) : to assign h to hrs and m to min.
void printTime( ) : to display values of hrs and min
time sumtime (time t1,time t2 ) : to add the timings given in the time objects t1 , t2 and returns them.

Write a main function to ask the user to input the values for two timings. Invoke appropriate functions to calculate sum of time. Print the given time and added time.

Answer

Logic: convert both times to minutes, add, then split back: hours = total / 60, minutes = total % 60 (35 + 45 = 80 min = 1 h 20 min carries one hour).

import java.util.Scanner;

class time {
    int hrs, min;                       // hours and minutes

    // constructor: 0 to hrs and min
    time() {
        hrs = 0;
        min = 0;
    }

    // assigns h to hrs and m to min
    void gettime(int h, int m) {
        hrs = h;
        min = m;
    }

    void printTime() {                  // displays hrs and min
        System.out.println(hrs + " hrs " + min + " mins");
    }

    // adds t1 and t2, returns the sum
    time sumtime(time t1, time t2) {
        time t = new time();
        // everything in minutes
        int total = (t1.hrs + t2.hrs) * 60 + t1.min + t2.min;
        t.hrs = total / 60;             // carry whole hours over
        t.min = total % 60;
        return t;
    }

    public static void main(String args[]) {
        Scanner sc = new Scanner(System.in);
        time t1 = new time(), t2 = new time(), t3 = new time();
        System.out.print("Enter hours and minutes of Time1: ");
        t1.gettime(sc.nextInt(), sc.nextInt());
        System.out.print("Enter hours and minutes of Time2: ");
        t2.gettime(sc.nextInt(), sc.nextInt());
        t3 = t3.sumtime(t1, t2);
        System.out.print("\nTime1 : "); t1.printTime();
        System.out.print("Time2 : ");   t2.printTime();
        System.out.print("Sum   : ");   t3.printTime();
    }
}

3 45

Output (the typed input is not echoed)

Time1 : 6 hrs 35 mins
Time2 : 3 hrs 45 mins
Sum   : 10 hrs 20 mins

Concepts to recall

  • A method can take objects as parameters and return a new object.
  • Normalise with / 60 and % 60.
  • Scanner: nextInt() reads the next integer token.
Q19Recursion[10]

Class checker has been defined to check whether a number is palindrome or not. The details of the class are given below:

Data members:
num : long integer variable to store number
rev : long integer variable to store reverse of number

Methods :
Checker ( long z ) : constructor to assign ‘z’ to num
Long ReverseNum(long q): to reverse the number stored in num using Recursive Technique and store in ‘rev’. Return the reverse number.
void display( ) : to invoke recursive function and decide whether num is a palindrome number or not. Print the number along with suitable message in both cases.

Do not write the main function.

Answer

Recursion: each call moves the last digit of q onto the end of rev (\(rev = rev\times10 + q\%10\)) and recurses on \(q/10\); the base case \(q = 0\) returns rev. A number is a palindrome when it equals its reverse.

class Checker {
    long num;                   // the number
    long rev;                   // its reverse

    Checker(long z) {           // constructor
        num = z;
        rev = 0;
    }

    // recursive: moves the last digit of q onto rev
    long ReverseNum(long q) {
        if (q == 0)             // base case: no digits left
            return rev;
        rev = rev * 10 + q % 10;
        return ReverseNum(q / 10);
    }

    void display() {
        rev = 0;
        long r = ReverseNum(num);
        if (r == num)
            System.out.println(num + " is a palindrome number");
        else
            System.out.println(num + " is not a palindrome number");
    }
}

The question prints the class name as checker and the constructor as Checker, and the return type as Long; Java needs the constructor name to match the class, so Checker and the primitive long are used.

Tested with 12321, 12345 and 7 (main not required by the question):

Output

12321 is a palindrome number
12345 is not a palindrome number
7 is a palindrome number

Concepts to recall

  • Every recursive method needs a base case.
  • Last digit: q % 10; drop it: q / 10.
  • Reset rev before reversing again.

Q20Inheritance, Interfaces and Polymorphism[10]

Define class basepro and derived class dervpro to find the product of two numbers details of both the classes are given below:

Class name : basepro
Data members
n1,n2 : float variables whose product is to be determined.
Methods
void enter( ) : to input values of n1 and n2
void show( ) : to display values of n1 and n2

Class name : dervpro
Data members
result : float variable to store product.
Methods
void prod( ) : to accept values of n1 and n2 and to calculate their product using the concept of inheritance.
void disp( ) : to display values of n1 and n2 and their product.

The main function need not to be written.

Answer

n1 and n2 are declared protected so the subclass can use them; dervpro reuses enter() and show() through inheritance.

import java.util.Scanner;

class basepro {
    protected float n1, n2;           // the two numbers

    void enter() {                    // inputs n1 and n2
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter two numbers: ");
        n1 = sc.nextFloat();
        n2 = sc.nextFloat();
    }

    void show() {                     // displays n1 and n2
        System.out.println("n1 = " + n1 + ", n2 = " + n2);
    }
}

class dervpro extends basepro {
    float result;                     // product

    void prod() {
        enter();                      // inherited from basepro
        // n1, n2 are protected: visible here
        result = n1 * n2;
    }

    void disp() {
        // inherited display of n1 and n2
        show();
        System.out.println("Product = " + result);
    }
}

Test: dervpro d = new dervpro(); d.prod(); d.disp();

Sample input

2.5 4

Output (the typed input is not echoed)

Enter two numbers: n1 = 2.5, n2 = 4.0
Product = 10.0

Concepts to recall

  • class B extends A: B inherits A's non-private members.
  • protected: visible in subclasses.
  • Inherited methods are called directly (or as super.m()).
Q21Data Structures (dequeue)[10]

Some declarations in the memory are made in such a way that can store numbers having a decimal point also and a number can be stored either at the front or at the back depending upon the availability of space. There may be at the most hundred numbers that can be stored. A class someprocess is defined to perform such kind of process as given above. The details of the class someprocess are as follows:

Class name : someprocess
Data members
line [ ] : double type array to hold numbers maximum size 100.
capacity : integer as the maximum storage capacity of the Line [ ].
front : integer to point to the index of front of the queue.
rear : integer to point to the index of rear of the quque.
num : double type variable to store a number.
Methods
someprocess( ) : constructor to assign 100 to capacity,-1 to front and rear.
int IsEmpty( ) : returns 1 if line is empty otherwise returns 0
void InsertRear( ) : accepts num if line is empty and inserts at the rear of line, otherwise output “line is full”.
void InsertFront( ) : accepts num if line is empty and inserts at the front of line, otherwise output “line is full”.
double DeleteFront( ) : removes the number from the front of line if the line is not empty otherwise output message “line is empty” and returns -999.99.
double DeleteRear( ) : removes the number from the rear of line if the line is not empty otherwise output message “line is empty” and returns -999.99.
void LineDisplay( ) : to display the elements of line if line is not empty, otherwise display message “line is empty”.

Answer

This is a double-ended queue (dequeue) in an array. front = rear = −1 means empty. A number can go in at the rear while rear < capacity−1, and at the front while front > 0 (or when the line is empty).

“accepts num if line is empty” is evidently meant as “if there is space” (if line is not full), which is what the methods below do.

import java.util.Scanner;

class someprocess {
    double line[] = new double[100];
    int capacity, front, rear;
    double num;
    static Scanner sc = new Scanner(System.in);

    someprocess() {
        capacity = 100;
        // -1 marks an empty line
        front = rear = -1;
    }

    int IsEmpty() {
        return (front == -1) ? 1 : 0;
    }

    void InsertRear() {
        // no room at the rear end
        if (rear == capacity - 1) {
            System.out.println("line is full");
            return;
        }
        System.out.print("Enter number: ");
        num = sc.nextDouble();
        if (front == -1)                      // first element
            front = 0;
        line[++rear] = num;
    }

    void InsertFront() {
        // no room before the front element
        if (front == 0) {
            System.out.println("line is full");
            return;
        }
        System.out.print("Enter number: ");
        num = sc.nextDouble();
        // empty line: first element
        if (front == -1) {
            front = rear = 0;
            line[0] = num;
        } else
            line[--front] = num;
    }

    double DeleteFront() {
        if (IsEmpty() == 1) {
            System.out.println("line is empty");
            return -999.99;
        }
        num = line[front];
        // last element removed
        if (front == rear)
            front = rear = -1;
        else
            front++;
        return num;
    }

    double DeleteRear() {
        if (IsEmpty() == 1) {
            System.out.println("line is empty");
            return -999.99;
        }
        num = line[rear];
        if (front == rear)
            front = rear = -1;
        else
            rear--;
        return num;
    }

    void LineDisplay() {
        if (IsEmpty() == 1) {
            System.out.println("line is empty");
            return;
        }
        for (int i = front; i <= rear; i++)
            System.out.print(line[i] + "  ");
        System.out.println();
    }
}

Test sequence: display, DeleteFront on empty, InsertRear 2.5, InsertRear 4.0, InsertFront (front = 0, so full at the front), display, DeleteFront, InsertFront 1.5, display, DeleteRear twice, IsEmpty, display.

Sample input

2.5
4.0
1.5

Output (the typed input is not echoed)

line is empty
line is empty
-999.99
Enter number: Enter number: line is full
2.5  4.0  
Deleted from front: 2.5
Enter number: 1.5  4.0  
Deleted from rear: 4.0
Deleted from rear: 1.5
IsEmpty = 1
line is empty

Concepts to recall

  • Dequeue: insertion and deletion at both ends.
  • Linear array dequeue: front insertion needs front > 0; rear insertion needs rear < size−1.
  • Reset front = rear = −1 when the last element is removed.
Q22(b)Complexity and Big O notation[2]

b) What is a Big O Notation ? Give the notation for a quadratic time.

Answer

Big O notation expresses the upper bound of an algorithm's running time (or space) as a function of the input size n, keeping only the dominant term and ignoring constant factors: \(f(n)=O(g(n))\) if \(f(n)\le c\,g(n)\) for some constant c and all large n. It describes how the time grows as n grows.

Quadratic time: \(O(n^2)\) — e.g. two nested loops each running n times (bubble sort).

Concepts to recall

  • Keep the dominant term, drop constants: \(3n^2+5n+7 = O(n^2)\).
  • Common orders: \(O(1) < O(\log n) < O(n) < O(n\log n) < O(n^2)\).
