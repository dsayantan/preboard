Q1Boolean Algebra[1]

State Absorption law and prove it using Truth Table.

Answer

Absorption law: \(A + A\cdot B = A\) and its dual \(A\cdot(A + B) = A\).

Proof of \(A + AB = A\) (the dual is proved the same way):

ABA·BA + A·BA + BA·(A + B)
000000
010010
100111
111111

The column \(A + A\cdot B\) (and the column \(A\cdot(A+B)\)) is identical to column \(A\) in every row, hence \(A + AB = A,\quad A(A+B) = A\)

Concepts to recall

  • Absorption: \(A + AB = A\); dual \(A(A+B) = A\).
  • Two expressions are equal when their truth-table columns agree in every row.

Q3Boolean Algebra[1]

Simplify algebraically \(C\overline{D} + A + A + \overline{C}\cdot\overline{D} + A\cdot B\)

Answer

\(= A + A + AB + C\overline{D} + \overline{C}\,\overline{D}\)

\(= A + AB + \overline{D}(C + \overline{C})\)   (idempotence \(A + A = A\); factorise \(\overline{D}\))

\(= A + \overline{D}\cdot 1\)   (absorption \(A + AB = A\); \(C + \overline{C} = 1\))

\(= A + \overline{D}\)

Concepts to recall

  • Idempotence \(A + A = A\); complement \(C + C' = 1\).

Q4Boolean Algebra[1]

Find the complement of \([\overline{(AB)}A][\overline{(AB)}B]\) and reduce to minimum literals.

Answer

By De Morgan, the complement of a product is the sum of the complements:

\(\{[\overline{(AB)}A][\overline{(AB)}B]\}' = [\overline{(AB)}A]' + [\overline{(AB)}B]'\)

\(= (AB + A') + (AB + B')\)   (De Morgan on each bracket, involution \((AB)'' = AB\))

\(= (A' + B) + (A + B')\)   (\(A' + AB = A' + B\), \(B' + AB = B' + A\))

\(= (A + A') + (B + B') = 1\)

Complement = 1   (the given expression itself is \(AB'\cdot A'B = 0\)).

Concepts to recall

  • De Morgan: \((XY)' = X' + Y'\), \((X + Y)' = X'Y'\).
  • \(A' + AB = A' + B\) (redundant-literal rule).
Q5Boolean Algebra[1]

Express in POS form: \(AB + \overline{C}\)   Give the final answer in Cardinal form.

Answer

F(A, B, C) is 1 when \(AB = 1\) (rows 110, 111) or \(C' = 1\) (rows 000, 010, 100, 110):

\(F = \Sigma(0, 2, 4, 6, 7)\), so F = 0 in rows 1 (001), 3 (011), 5 (101).

Q8Inheritance, Interfaces and Polymorphism[2]

Explain the use of 'super' and 'super( ) function'.

Answer

super (keyword as a reference): inside a subclass it refers to the members of the immediate superclass. It is used to reach a superclass variable or method that has been hidden or overridden in the subclass, e.g. super.display(); or super.x.

super( ) (constructor call): calls the constructor of the immediate superclass from the subclass constructor, passing it the arguments it needs, e.g. super(name, basic);. It must be the first statement of the subclass constructor; if it is omitted, Java inserts a call to the superclass's no-argument constructor.

Concepts to recall

  • super.member reaches the parent's version of an overridden/hidden member.
  • super(args) must be the first line of a subclass constructor.

Q10Arrays (address calculation)[2]

An array AR[15,20], stores elements in Row Major Wise, with the address AR[0][0] as 4000. If each element requires 8 bytes of storage, find the base address.

Answer

Row major: \(\text{Address}(AR[i][j]) = B + W\,[\,(i - L_r)\times N_c + (j - L_c)\,]\), with \(N_c = 20\) columns, \(W = 8\) bytes, lower bounds \(L_r = L_c = 0\).

The base address B is the address of the first element of the array, AR[0][0]. Putting i = j = 0:

\(4000 = B + 8[(0)(20) + 0] = B\)  ⇒  Base address B = 4000

[The question as printed gives the answer in its data — the address of AR[0][0] is the base address. For practice with the same data: the last element AR[14][19] is at \(4000 + 8(14\times20 + 19) = 4000 + 8\times299 = 6392\).]

Concepts to recall

  • Row major: \(B + W[(i-L_r)N_c + (j-L_c)]\); column major: \(B + W[(i-L_r) + (j-L_c)N_r]\).
  • Base address = address of the first element.

Q13(a)Computer Hardware (multiplexers)[3]

Briefly explain the working of 4:1 multiplexer and also draw a 4:1 multiplexer.

Answer

A multiplexer (data selector) has many data inputs, one output and select lines; the binary number on the select lines chooses which input is passed to the output. A 4:1 MUX has data inputs I0–I3, select lines S1 S0 and output Y:

\(Y = S_1'S_0'I_0 + S_1'S_0I_1 + S_1S_0'I_2 + S_1S_0I_3\). Each AND gate is enabled by one select combination (S1′S0′, S1′S0, S1S0′, S1S0); only that gate passes its input, and the OR gate delivers it to Y.

Concepts to recall

  • \(2^n\) data inputs need n select lines.
  • Each AND gate is a minterm of the select lines ANDed with one data input; the OR collects them.

Answer

So each sum term is a NOR gate (giving the complemented sum), and a final 3-input NOR of these gives F:

Concepts to recall

Q13(c)Computer Hardware (NAND, NOR as universal gates)[3]

Draw logic circuit of XNOR using NOR gate only.

Answer

Four NOR gates:

  • \(G_1 = (A + B)'\)
  • \(G_2 = (A + G_1)' = A'(A + B) = A'B\)
  • \(G_3 = (B + G_1)' = B'(A + B) = AB'\)
  • \(X = (G_2 + G_3)' = (A'B + AB')' = AB + A'B' = A \odot B\)

Concepts to recall

  • XNOR: \(A \odot B = AB + A'B'\), 1 when inputs are equal.
  • NOR is universal: NOT = NOR with inputs tied; OR = NOR followed by NOT.
Q14(a)Boolean Algebra[3]

Reduce the following Expression \(AB + \overline{AC} + A\overline{B}C(AB + C)\)

Answer

\(A\overline{B}C(AB + C) = A\overline{B}C\cdot AB + A\overline{B}C\cdot C = 0 + A\overline{B}C\)   (\(B\overline{B} = 0\), \(CC = C\))

Expression \(= AB + A' + C' + AB'C\)

\(= (A' + B + C') + (A' + B + C')' = 1\)   since \(AB'C = (A' + B + C')'\) and \(X + X' = 1\)

\(= 1\)

Concepts to recall

  • \(X\cdot X' = 0\), \(X + X' = 1\).
  • De Morgan: \((AC)' = A' + C'\).
  • Look for a term that is the complement of the rest.

Q14(c)Boolean Algebra / Computer Hardware[3]

Derive a Boolean expression for Out in the logic diagram given below and simplify it.

Answer

Output of each gate:

\(Out = (B + C + D')\,(A + C + D')\,(C' + D)\)

\(= (C + D' + AB)(C' + D)\)   (distributive law: \((X + B)(X + A) = X + AB\) with \(X = C + D'\))

\(= CC' + CD + C'D' + DD' + ABC' + ABD = CD + C'D' + ABC' + ABD\)

\(ABD = ABCD + ABC'D\); \(ABCD\) is contained in \(CD\) and \(ABC'D\) in \(ABC'\), so \(ABD\) is redundant:

\(Out = C'D' + CD + ABC'\)   i.e. \((C \odot D) + ABC'\)

Concepts to recall

  • Write each gate's output on the diagram, working from inputs to output.
  • \((X + A)(X + B) = X + AB\).
  • Consensus/absorption removes redundant terms.

Q15Recursion / Arrays[10]

Write a program to pack an array which is already sorted. To pack means to remove all duplicates from the array i.e. if the given array has the following numbers in order: 1,2,2,3,3,3,4,4,4,4,9,11,11,14,14,14
The resultant array should have the following numbers: 1,2,3,4,9,11,14

CLASS NAME : Pack
DATA MEMBERS
int size : to accept the size of the array
int n[ ] : to accept the values
METHODS
void packer(… ) : using recursion to pack the array n.
void printer( ) : Print the packed array n.

No need to write the main().

Answer

Logic. Because the array is sorted, equal values are adjacent. Keep an index k of the last value kept; compare each n[i] with n[k] — if different, copy it to n[k+1]. The recursion advances i by one each call; the base case i = size sets size = k + 1. (An accept() method is added to read the data.)

import java.util.Scanner;
class Pack {
    int size;       // number of elements currently in the array
    int n[];        // the sorted values

    // reads the size and the (already sorted) values
    void accept() {
        Scanner sc = new Scanner(System.in);
        size = sc.nextInt();
        n = new int[size];
        for (int i = 0; i < size; i++)
            n[i] = sc.nextInt();
    }

    // Recursive packing.
    // i : index of the element being examined
    // k : index of the last element kept so far (n[0..k] is already packed)
    void packer(int i, int k) {
        if (size == 0)
            return;
        if (i == size) {          // base case: every element examined
            size = k + 1;         // the packed array is n[0..k]
            return;
        }
        if (n[i] != n[k]) {       // a new value (sorted: no repeat later)
            k++;
            n[k] = n[i];          // move it next to the last kept value
        }
        packer(i + 1, k);         // smaller problem: one element fewer
    }

    // prints the packed array
    void printer() {
        for (int i = 0; i < size; i++)
            System.out.print(n[i] + (i < size - 1 ? "," : "\n"));
    }
}

Concepts to recall

  • Every recursion needs a base case (here i == size) and a smaller sub-problem (i + 1).
  • Sorted ⇒ duplicates are adjacent, so one pass suffices.

Define the main( ) function to create objects and call the methods accordingly to enable the task.

Answer

[A constructor has no return type, so "void common(int nn)" is written as the constructor Common(int nn).]

import java.util.Scanner;
class Common {
    int arr[];      // elements of this object's array
    int n;          // size of the array
    static Scanner sc = new Scanner(System.in);

    // constructor: stores the size and creates the array
    // (the paper writes "void common(int nn)"; a constructor has no return type)
    Common(int nn) {
        n = nn;
        arr = new int[n];
    }

    // reads n elements, rejecting a value already entered (no duplicates)
    void accept() {
        System.out.println("Enter " + n + " distinct elements:");
        int i = 0;
        while (i < n) {
            int v = sc.nextInt();
            boolean dup = false;
            for (int j = 0; j < i; j++)
                if (arr[j] == v)
                    dup = true;
            if (dup)
                System.out.println(v + " already entered, enter another value");
            else
                arr[i++] = v;
        }
    }

    // prints the elements of this object that also occur in object A
    void display(Common A) {
        boolean found = false;
        System.out.print("Common elements: ");
        for (int i = 0; i < n; i++)
            for (int j = 0; j < A.n; j++)
                if (arr[i] == A.arr[j]) {   // A's array, reached through the object
                    System.out.print(arr[i] + " ");
                    found = true;
                }
        if (!found)
            System.out.print("none - no common element found");
        System.out.println();
    }

    public static void main(String args[]) {
        System.out.println("Size of first array: ");
        Common ob1 = new Common(sc.nextInt());
        ob1.accept();
        System.out.println("Size of second array: ");
        Common ob2 = new Common(sc.nextInt());
        ob2.accept();
        ob1.display(ob2);
    }
}

Q17Arrays, Strings[10]

A class MIDSORT rearranges the alphabets of a word by keeping the smallest in the centre and then next bigger one in left and then next bigger one in the right and so on. Members of the class are shown below.

Data members
String word – to accept a word from user.
int len – to accept size of the word.

Member function
void readdata( ) : to accept a word for sen.
void centre ( ) : to change the word as shown below.

Input : flower   Output : wofelr
Input : trouble   Output : toeblru

void print ( ) : to print the changed word

No need to write the main().

Answer

Logic. Sort the letters (flower → e f l o r w). Put the smallest at the centre index len/2, then place the rest alternately to the left and to the right of what is already placed: e at 3, f at 2, l at 4, o at 1, r at 5, w at 0 → w o f e l r.

import java.util.Scanner;
class MIDSORT {
    String word;    // the word entered (later, the rearranged word)
    int len;        // its length

    // reads a word
    void readdata() {
        Scanner sc = new Scanner(System.in);
        System.out.println("Enter a word: ");
        word = sc.next();
        len = word.length();
    }

    // smallest letter in the centre, then the next bigger to its left,
    // the next to its right, and so on alternately
    void centre() {
        char c[] = word.toCharArray();
        // bubble sort the letters in ascending order
        for (int i = 0; i < len - 1; i++)
            for (int j = 0; j < len - 1 - i; j++)
                if (c[j] > c[j + 1]) {
                    char t = c[j]; c[j] = c[j + 1]; c[j + 1] = t;
                }
        char res[] = new char[len];
        int mid = len / 2;           // centre position
        res[mid] = c[0];             // smallest letter in the centre
        int left = mid - 1, right = mid + 1;
        for (int k = 1; k < len; k++) {
            if (k % 2 == 1)          // 1st, 3rd, 5th ... next letters go to the left
                res[left--] = c[k];
            else                     // 2nd, 4th, 6th ... go to the right
                res[right++] = c[k];
        }
        word = new String(res);
    }

    // prints the changed word
    void print() {
        System.out.println("Output : " + word);
    }
}

Q18Data Structures (single linked list)[5]

Write a program to create a node class of one data and one link only. Then assume that a linked list already exists with data and create a llist class as following:

Data members: Start : object of node type
Member functions :
Displayfront_ from_pos( ) : This function accepts a position and displays the nodes from that position e.g. if pos is 3 this function will display 44,55,66
Displayback_ from_pos( ) : This function accepts a position and displays the nodes back from that position e.g. if pos is 3 this function will display 44,33,22

No need to write the main function.

Answer

Logic. Forward: walk pos − 1 links from Start, then print to the end. Backward: the links go only forward, so walk from Start to the pos-th node, building the output string by putting each new value in front — the string then reads from node pos back to node 1.

class Node {
    int data;       // the one data field
    Node link;      // the one link: reference to the next node

    Node(int d) {
        data = d;
        link = null;
    }
}

class LList {
    Node Start;     // first node of the list (the list already exists)

    // displays the nodes from position pos (1-based) to the end
    void Displayfront_from_pos(int pos) {
        Node p = Start;
        int i = 1;
        while (p != null && i < pos) {   // walk to the pos-th node
            p = p.link;
            i++;
        }
        if (p == null || pos < 1) {
            System.out.println("Invalid position");
            return;
        }
        String s = "";
        while (p != null) {               // print it and every node after it
            s = s + p.data + (p.link != null ? "," : "");
            p = p.link;
        }
        System.out.println(s);
    }

    // displays the nodes from position pos back to the first node.
    // The links only go forward, so the nodes are collected in order and
    // printed in reverse (each new value is put in FRONT of the string).
    void Displayback_from_pos(int pos) {
        Node p = Start;
        int i = 1;
        String s = "";
        while (p != null && i <= pos) {
            s = (i == 1) ? "" + p.data : p.data + "," + s;
            p = p.link;
            i++;
        }
        if (i <= pos || pos < 1) {        // list ended before reaching pos
            System.out.println("Invalid position");
            return;
        }
        System.out.println(s);
    }
}

Run on the list 22 → 33 → 44 → 55 → 66 with pos = 3, 3, 1, 5, 7 (forward, back, forward, back, forward):

Output

44,55,66
44,33,22
22,33,44,55,66
66,55,44,33,22
Invalid position

Concepts to recall

  • Traverse with p = p.link until p == null.
  • A singly linked list cannot be walked backwards: reverse by collecting (or by recursion).

Q19(b)Complexity and Big O notation[1]

What is the worst case complexity of the following program code.

for( int i=1; i<N; i++)
{
  for( int j=1; j<M; j++)
  {
   Statements;
  }
}

Answer

The outer loop runs N − 1 times and, for each, the inner loop runs M − 1 times, so Statements execute (N − 1)(M − 1) times. Dropping constants and lower-order terms: O(N × M) (O(N²) when M = N).

Concepts to recall

  • Nested independent loops multiply.
  • Big O keeps only the dominant term, without constants.
Q20Inheritance, Interfaces and Polymorphism[5]

A super class 'employee' has been defined to define the basic details of an employee. Define a subclass 'salary' to compute the area of the gross pay of the employee and print the name and gross pay by using the required data member of the super class.

The details of the members of the class are given below:

class name : employee
data members
name : to store the name of employee
basicpay : to store the basic pay of the employee
DA : to store the DA
methods
employee(...) : parameterized constructor to assign values to data members.
void calDA( ) : calculates DA at the rate of 35% of basicpay.

class name : salary
data members
grosspay : to calculate and store the gross pay of employee ( basicpay +DA)
methods
salary(...) : parameterised constructor to assign values to data members.
void calGP() : compute the grosspay
void show() : displays the name,basicpay,DA,Grosspay of employee

The main function and algorithm need not be written.

Answer

The superclass is shown for completeness (the question says it is already defined); the answer is the subclass salary.

class employee {                    // the super class, as described in the paper
    String name;
    double basicpay;
    double DA;

    employee(String n, double b) {
        name = n;
        basicpay = b;
        DA = 0.0;
    }

    void calDA() {
        DA = 0.35 * basicpay;       // 35% of basic pay
    }
}

class salary extends employee {
    double grosspay;                // basic pay + DA

    // passes name and basic pay up to the super class constructor
    salary(String n, double b) {
        super(n, b);
        grosspay = 0.0;
    }

    void calGP() {
        calDA();                    // make sure DA is computed first
        grosspay = basicpay + DA;   // inherited members used directly
    }

    void show() {
        System.out.println("Name       : " + name);
        System.out.println("Basic pay  : " + basicpay);
        System.out.println("DA         : " + DA);
        System.out.println("Gross pay  : " + grosspay);
    }
}

Test (name Amit Sen, basic pay 20000):

Output

Name       : Amit Sen
Basic pay  : 20000.0
DA         : 7000.0
Gross pay  : 27000.0

Concepts to recall

  • class salary extends employee; super(n, b) first in the constructor.
  • Inherited (non-private) fields are used directly in the subclass.
