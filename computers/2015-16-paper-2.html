Answer

Answer as the practical expects it: the algorithm, then the documented Java program, then the output for the paper's sample data and for further inputs — every output below is from an actual run of this program (JDK 11).

Reading the samples. The outer ring is filled clockwise (1 → 12 for n = 4). The next ring starts at its top-left corner but goes down first — anticlockwise (13 at [1][1], 14 below it, 15, 16). For n = 6 the third ring (33–36) is clockwise again. So the rings alternate: even-numbered rings (0, 2, …) clockwise, odd-numbered rings anticlockwise, always starting at the ring's top-left corner. An ordinary one-way spiral would give the wrong matrix for every sample.

Algorithm

  1. Start. Input n; if n < 1 print "INVALID SIZE" and stop. Create m[n][n]; k ← 1.
  2. For ring r = 0 to (n+1)/2 − 1: lo ← r, hi ← n−1−r.
  3. If lo = hi (centre cell of odd n): m[lo][lo] ← k; go to step 7.
  4. If r is even (clockwise): fill the top row m[lo][lo..hi] left to right, the right column m[lo+1..hi][hi] downwards, the bottom row m[hi][hi−1..lo] right to left, the left column m[hi−1..lo+1][lo] upwards, putting k and incrementing it each time.
  5. If r is odd (anticlockwise): fill the left column m[lo..hi][lo] downwards, the bottom row m[hi][lo+1..hi] left to right, the right column m[hi−1..lo][hi] upwards, the top row m[lo][hi−1..lo+1] right to left.
  6. Next r.
  7. Print the matrix row by row. Stop.

Program

import java.util.Scanner;

/* Fills an n x n matrix with 1 .. n*n ring by ring, from the outside in.
 * As the paper's three samples show, the rings alternate in direction:
 *   ring 0, 2, 4 ... clockwise      (start top-left, go RIGHT first)
 *   ring 1, 3, 5 ... anticlockwise  (start top-left, go DOWN first)  */
class CircularMatrix {
    int n;          // order of the matrix
    int m[][];      // the matrix

    CircularMatrix(int size) {
        n = size;
        m = new int[n][n];
    }

    void fill() {
        int k = 1;                              // next value to place
        for (int r = 0; r < (n + 1) / 2; r++) { // r = ring number
            int lo = r, hi = n - 1 - r;         // first and last row/column of this ring
            if (lo == hi) {                     // odd n: the single centre cell
                m[lo][lo] = k++;
                break;
            }
            if (r % 2 == 0) {                   // clockwise ring
                for (int j = lo; j <= hi; j++)     m[lo][j] = k++;   // top row, left to right
                for (int i = lo + 1; i <= hi; i++) m[i][hi] = k++;   // right column, down
                for (int j = hi - 1; j >= lo; j--) m[hi][j] = k++;   // bottom row, right to left
                for (int i = hi - 1; i > lo; i--)  m[i][lo] = k++;   // left column, up
            } else {                            // anticlockwise ring
                for (int i = lo; i <= hi; i++)     m[i][lo] = k++;   // left column, down
                for (int j = lo + 1; j <= hi; j++) m[hi][j] = k++;   // bottom row, left to right
                for (int i = hi - 1; i >= lo; i--) m[i][hi] = k++;   // right column, up
                for (int j = hi - 1; j > lo; j--)  m[lo][j] = k++;   // top row, right to left
            }
        }
    }

    void display() {
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++)
                System.out.print(String.format("%4d", m[i][j]));
            System.out.println();
        }
    }

    public static void main(String args[]) {
        Scanner sc = new Scanner(System.in);
        System.out.println("Enter the size n: ");
        int size = sc.nextInt();
        if (size < 1) {
            System.out.println("INVALID SIZE");
            return;
        }
        CircularMatrix ob = new CircularMatrix(size);
        ob.fill();
        ob.display();
    }
}

Answer as the practical expects it: the algorithm, then the documented Java program, then the output for the paper's sample data and for further inputs — every output below is from an actual run of this program (JDK 11).

Idea. Number the weekdays Sunday = 0 … Saturday = 6; 1 January is Thursday = 4. The 1st of any month falls on (4 + number of days in all earlier months) mod 7 — e.g. March: (4 + 31 + 28) mod 7 = 63 mod 7 = 0, Sunday. 2015 is not a leap year, so February has 28 days. As in the samples, cells before the 1st are blank and cells after the last day up to Saturday hold '*'.

Algorithm

  1. Start. Store month names and days[] = {31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31}.
  2. Input the month name; find its index m (0–11) ignoring case. If not found, print "INVALID MONTH NAME" and stop.
  3. total ← sum of days[0..m−1]; start ← (4 + total) mod 7.
  4. Print the heading Sun … Sat. col ← 0.
  5. Print start blank cells, col ← start.
  6. For d = 1 to days[m]: print d in a cell; col ← col + 1; if col = 7, go to a new line and col ← 0.
  7. If col ≠ 0, print '*' cells until col = 7. Stop.

Program

import java.util.Scanner;

/* Prints the calendar of any month of 2015, given that 1 January 2015 was a
 * Thursday.  Day numbers: 0 = Sunday, 1 = Monday, ... 6 = Saturday.
 * As in the paper's samples, cells before day 1 are left blank and the
 * cells after the last day, up to Saturday, are filled with '*'.          */
class Calendar2015 {
    String names[] = {"JANUARY", "FEBRUARY", "MARCH", "APRIL", "MAY", "JUNE", "JULY",
                      "AUGUST", "SEPTEMBER", "OCTOBER", "NOVEMBER", "DECEMBER"};
    int days[] = {31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};   // 2015 is not a leap year
    String head[] = {"Sun", "Mon", "Tues", "Wed", "Thrus", "Fri", "Sat"};  // as printed
    int month;      // 0 .. 11, or -1 if the name is not a month

    // finds the month number from its name (case ignored)
    void setMonth(String s) {
        month = -1;
        for (int i = 0; i < 12; i++)
            if (names[i].equalsIgnoreCase(s.trim()))
                month = i;
    }

    // weekday of the 1st of the month: Thursday (4) plus all the days before it, mod 7
    int firstDay() {
        int total = 0;
        for (int i = 0; i < month; i++)
            total += days[i];
        return (4 + total) % 7;
    }

    void print() {
        if (month == -1) {
            System.out.println("INVALID MONTH NAME");
            return;
        }
        int start = firstDay();
        for (int i = 0; i < 7; i++)
            System.out.print(String.format("%-7s", head[i]));
        System.out.println();
        int col = 0;
        for (int i = 0; i < start; i++) {          // blanks before the 1st
            System.out.print(String.format("%-7s", ""));
            col++;
        }
        for (int d = 1; d <= days[month]; d++) {
            System.out.print(String.format("%-7d", d));
            col++;
            if (col == 7) {                         // Saturday done: new line
                System.out.println();
                col = 0;
            }
        }
        if (col != 0) {                             // fill the last week with '*'
            while (col < 7) {
                System.out.print(String.format("%-7s", "*"));
                col++;
            }
            System.out.println();
        }
    }

    public static void main(String args[]) {
        Scanner sc = new Scanner(System.in);
        System.out.println("Enter the name of a month of 2015:");
        Calendar2015 ob = new Calendar2015();
        ob.setMonth(sc.nextLine());
        ob.print();
    }
}

Q3Arrays, Strings[20]

Question 3: A new type of encryption system was made to keep the alphabetic sentence a bit more secure by merging the word of a sentence. The system is categorized in two categories:

Category 1 : If the number of words in the sentence is of odd numbers.

Sample input/output:
Original Sentence : THE DOG JUMPS OVER THE BLACK CAT.
Encrypted Sentence : TCHAET   DBOLGA*C*K   JTUHMEP*S*   *REVO*

The Encryption system will merge in the following way-

WordsMerged
'THE' and 'CAT'→TCHAET(If the words are of same length)
'DOG' and 'BLACK'→DBOLGA*C*K(If the second word is lengthier than the first)
'JUMPS' and 'THE'→JTUHMEP*S*(If the first word is lengthier than the Second)
'OVER'→*REVO*

(the extra word which do not has a pair is reversed and then prefixed and suffixed with '*')

Category 2 : If the number of words in the sentence is of even numbers.

Sample input/output:
Original Sentence : ASHOK IS AN INDIAN
Encrypted Sentence : AISNHDOIKA*N   IASN

The Encryption system will merge in the following way-

WordsMerged
'ASHOK' and 'INDIAN'→AISNHDOIKA*N(If the second word is lengthier than the first)
'IS' and 'AN'→IASN(If the words are of same length)

Write a program

i) to accept an Encrypted word/ sentence and display the original word/sentence.
ii) to accept an the original word/sentence and display Encrypted word/ sentence.

Answer

Answer as the practical expects it: the algorithm, then the documented Java program, then the output for the paper's sample data and for further inputs — every output below is from an actual run of this program (JDK 11).

Reading the samples. Word 1 is paired with the last word, word 2 with the last-but-one, and so on. A pair is merged letter by letter — first word's letter, then second word's — and where the shorter word has run out its turn is filled with '*' (DOG + BLACK: D B O L G A * C * K). With an odd number of words the middle word is left over and written reversed between two '*'. The full stop is not part of the encrypted text.

Decrypting reverses this: a token that begins with '*' is the middle word (a merged token always begins with a letter of the first word); in every other token the characters at even positions (0, 2, 4, …) form the first word and those at odd positions the second, ignoring '*'. The k-th token gives word k and word n−1−k.

Algorithm

  1. Start. Input the choice (1 = decrypt, 2 = encrypt) and the sentence; convert to upper case; drop a final '.', '?' or '!'. Split into words w[0..n−1].
  2. Encrypt: for i = 0 to n/2 − 1: t ← "" ; for j = 0 to max(len(w[i]), len(w[n−1−i])) − 1: append w[i][j] (or '*' if j ≥ its length), then w[n−1−i][j] (or '*'). Output t.
  3. If n is odd, output "*" + reverse(w[n/2]) + "*".
  4. Decrypt: tokens t[0..p−1]. If the last token starts with '*', it is the middle word: mid ← reverse of it without the two stars, pairs ← p − 1, n ← 2·pairs + 1; else pairs ← p, n ← 2·pairs.
  5. For k = 0 to pairs − 1: a ← characters of t[k] at even positions, b ← those at odd positions, skipping '*'; w[k] ← a, w[n−1−k] ← b.
  6. If n is odd, w[n/2] ← mid. Output w[0..n−1] separated by spaces. Stop.

Program

import java.util.Scanner;
import java.util.StringTokenizer;

/* Merge cipher.
 * Encrypt: pair word 1 with the last word, word 2 with the last-but-one, ...
 *   A pair is merged letter by letter, first word's letter first; where the
 *   shorter word has run out its place is taken by '*'.
 *   With an odd number of words the middle word has no partner: it is
 *   reversed and written as *...*.
 * Decrypt: a token beginning with '*' is the middle word; in every other token
 *   the letters at even positions belong to the first word of the pair and
 *   those at odd positions to the second ('*' fillers are dropped).          */
class MergeCipher {

    // splits a sentence into words, dropping the full stop / ? / ! at the end
    String[] words(String s) {
        s = s.trim();
        char last = s.charAt(s.length() - 1);
        if (last == '.' || last == '?' || last == '!')
            s = s.substring(0, s.length() - 1);
        StringTokenizer st = new StringTokenizer(s);
        String w[] = new String[st.countTokens()];
        for (int i = 0; i < w.length; i++)
            w[i] = st.nextToken();
        return w;
    }

    // merges two words, padding the shorter one with '*'
    String merge(String a, String b) {
        String r = "";
        int L = Math.max(a.length(), b.length());
        for (int i = 0; i < L; i++) {
            r += (i < a.length()) ? a.charAt(i) : '*';
            r += (i < b.length()) ? b.charAt(i) : '*';
        }
        return r;
    }

    String reverse(String a) {
        String r = "";
        for (int i = a.length() - 1; i >= 0; i--)
            r += a.charAt(i);
        return r;
    }

    String encrypt(String sentence) {
        String w[] = words(sentence);
        int n = w.length;
        String out = "";
        for (int i = 0; i < n / 2; i++)             // the pairs, outside in
            out += merge(w[i], w[n - 1 - i]) + " ";
        if (n % 2 == 1)                             // the unpaired middle word
            out += "*" + reverse(w[n / 2]) + "*";
        return out.trim();
    }

    String decrypt(String code) {
        String t[] = words(code);
        int pairs = t.length, mid = 0;
        String middle = "";
        if (t[t.length - 1].charAt(0) == '*') {     // last token is the middle word
            pairs = t.length - 1;
            mid = 1;
            String m = t[t.length - 1];
            middle = reverse(m.substring(1, m.length() - 1));
        }
        int n = 2 * pairs + mid;                    // number of words in the sentence
        String w[] = new String[n];
        for (int k = 0; k < pairs; k++) {
            String a = "", b = "";
            for (int i = 0; i < t[k].length(); i++) {
                char ch = t[k].charAt(i);
                if (ch == '*')
                    continue;                       // filler, not a letter
                if (i % 2 == 0) a += ch; else b += ch;
            }
            w[k] = a;                               // k-th word from the front
            w[n - 1 - k] = b;                       // k-th word from the back
        }
        if (mid == 1)
            w[n / 2] = middle;
        String out = "";
        for (int i = 0; i < n; i++)
            out += w[i] + (i < n - 1 ? " " : "");
        return out;
    }

    public static void main(String args[]) {
        Scanner sc = new Scanner(System.in);
        MergeCipher ob = new MergeCipher();
        System.out.println("1. Encrypted to original   2. Original to encrypted");
        int ch = Integer.parseInt(sc.nextLine().trim());
        System.out.println("Enter the word / sentence:");
        String s = sc.nextLine().toUpperCase();
        if (s.trim().length() == 0) {
            System.out.println("INVALID INPUT");
            return;
        }
        if (ch == 1)
            System.out.println("Original Sentence : " + ob.decrypt(s));
        else if (ch == 2)
            System.out.println("Encrypted Sentence : " + ob.encrypt(s));
        else
            System.out.println("INVALID CHOICE");
    }
}
