Q1(i)Inheritance, Interfaces and Polymorphism — interfaces[1]

If a class implements an interface, what must it do?

A) Implement all methods of the interface
B) Extend the interface
C) Declare the interface as a variable
D) Provide a constructor for the interface

Answer

An interface only declares method prototypes; a (non-abstract) class that implements it promises to supply a body for every one of them. A class implements an interface (it does not extend it), and an interface has no constructor.

A) Implement all methods of the interface

Concepts to recall

  • class C implements I: C must define every abstract method of I (or itself be declared abstract).
  • Interfaces cannot be instantiated and have no constructors.
Q1(ii)Inheritance, Interfaces and Polymorphism — interfaces[1]

Assertion: A class that implements an interface must implement all of its methods.
Reasoning: If a class does not implement all methods, it can still be instantiated.

A) Both assertion and reasoning are true.
B) Both assertion and reasoning are false.
C) The assertion is true, but the reasoning is false.
D) The assertion is false, but the reasoning is true.

Answer

Assertion — true. A concrete class implementing an interface must define all of its abstract methods, or the compiler reports an error.
Reasoning — false. A class that leaves any interface method undefined must be declared abstract, and an abstract class cannot be instantiated.

C) The assertion is true, but the reasoning is false.

Concepts to recall

  • Judge the Assertion and the Reasoning separately, each as a statement on its own; then pick the option that matches the pair.
  • A class missing any abstract method must be abstract; new cannot create an object of an abstract class.

Q1(iv)Computer Hardware — encoders[1]

Assertion: Encoders can only work with binary inputs.
Reasoning: This limitation makes them unsuitable for other number systems.

A) Both assertion and reasoning are true.
B) Both assertion and reasoning are false.
C) The assertion is true, but the reasoning is false.
D) The assertion is false, but the reasoning is true.

Answer

Assertion — false. An encoder has 2n (or fewer) input lines, one per symbol, and produces the n-bit binary code of the active line. Its inputs represent digits of other systems — the decimal-to-BCD (10 → 4) encoder and the octal-to-binary (8 → 3) encoder are the standard examples.
Reasoning — false. Encoders are used precisely to convert decimal, octal (or keyboard) inputs into binary, so they are not unsuitable for other number systems.

Each input line of an encoder carries a binary logic level (0 or 1), as in every digital circuit; the assertion is about which number system the inputs represent, and there it is false.

B) Both assertion and reasoning are false.

Concepts to recall

  • Judge the Assertion and the Reasoning separately, each as a statement on its own; then pick the option that matches the pair.
  • Encoder: 2n inputs → n outputs (e.g. octal to binary 8:3, decimal to BCD 10:4). Decoder: n inputs → 2n outputs.

Q1(vi)Complexity and Big O notation[1]

What is the Big O complexity for the following code segment?

for(int k=0;k<n;k++)
         s+=k;

a) O(n)   b) O(n*n)   c) O(n2)   d) O(1)

Answer

The loop body s += k is a constant-time statement and it executes once for each k = 0, 1, …, n − 1, i.e. n times. Total work \(= c \cdot n\), so the complexity is linear.

a) O(n)

Concepts to recall

  • A single loop running n times with an O(1) body → O(n).
  • Nested loops each running n times → O(n2); drop constants and lower terms.

Q1(ix)Objects — input/output exceptions[1]

What is an exception?

Answer

An exception is an abnormal condition (a run-time error) that occurs during the execution of a program and disrupts its normal flow — e.g. dividing an integer by zero (ArithmeticException), an array index out of range, or an input/output failure (IOException). Java represents it as an object of a subclass of Exception, which is thrown and can be caught and handled with try … catch.

An exception is a run-time error event that interrupts the normal flow of a program.

Concepts to recall

  • Exception = run-time error object; handled with try–catch (or declared with throws).
  • Examples: ArithmeticException, ArrayIndexOutOfBoundsException, IOException, InputMismatchException.

Q2(iii)Complexity and Big O notation[1]

Write the order of complexity for an if else statement.

Answer

Only one of the two branches executes, so the cost is the test plus the larger branch. When the branches are simple (constant-time) statements this does not depend on n:

O(1) (in general, O(max of the two branches)).

Concepts to recall

  • Sequence: add the costs. if–else: cost of the condition + the costlier branch.
  • Constant amount of work → O(1).

Given the Boolean function: \(F(A,B,C,D) = \Sigma(5,6,7,8,9,10,11,14,15)\)

i) Reduce the above expression by using 4-variable K map, showing the various groups (i.e., octet, quads and pairs)

Answer

Place 1s in cells 5, 6, 7, 8, 9, 10, 11, 14, 15 (0s elsewhere):

Quad 1 (8, 9, 11, 10) — row AB′: \(AB'\)
Quad 2 (7, 6, 15, 14) — B = 1, C = 1 in all four: \(BC\)
Pair (5, 7) — A′B with D = 1: \(A'BD\)
Every 1 is covered and no group is redundant (cell 5 has no larger group: 13 and 4 are 0).

Concepts to recall

  • K-map rows and columns in Gray code: 00, 01, 11, 10 — cell numbers 0 1 3 2 / 4 5 7 6 / 12 13 15 14 / 8 9 11 10.

Q5(a)Computer Hardware — multiplexers[3]

A 4x1 MUX is shown in the figure below: Write the output of Z using exclusive gates.

Answer

Taking S1 = A as the more significant select bit and S2 = B as the less significant one, a 4 × 1 MUX gives

\(Z = A'B'I_0 + A'BI_1 + AB'I_2 + ABI_3\)

Substitute \(I_0 = I_1 = C\) and \(I_2 = I_3 = C'\):

Q6Recursion; Strings[10]

Design a class Duplicate to remove all duplicate characters from the string and find the resultant string. The details of the members of the class are given below:

Class nameDuplicate
Data members/instance variables:
wrdstores a String
nwstores the modified string
lento store the length of the word
Methods/Member functions:
Duplicate( )default constructor
void acceptword( )to accept the string
String remvDup (String,String,int )to remove all duplicate characters from the string and find the resultant string using recursion
void display( )displays the modified string along with an appropriate message.

Specify the class Duplicate giving details of the constructor, void acceptword( ), String remvDup( ) and void display( ). Define the main( ) function to create an object and call the functions accordingly to enable the task.

Answer

Idea: remvDup(s, r, i) examines character i of s; it is appended to the result r only if r does not already contain it (so the first occurrence of each character is kept). The base case is i = len, when the whole string has been examined and r is returned.

import java.util.Scanner;

public class Duplicate
{
    String wrd;     // the original string
    String nw;      // the string with duplicate characters removed
    int len;        // length of wrd

    // default constructor
    Duplicate()
    {
        wrd = "";
        nw = "";
        len = 0;
    }

    // accepts the string
    void acceptword()
    {
        Scanner sc = new Scanner(System.in);
        System.out.println("Enter a string :");
        wrd = sc.nextLine();
        len = wrd.length();
    }

    /* Recursive: s is the original string, r the result built so far,
       i the index of the character being examined.
       A character is added to r only if it is not already in r,
       so only its first occurrence survives. */
    String remvDup(String s, String r, int i)
    {
        // base case: whole string examined
        if (i == len)
            return r;
        char ch = s.charAt(i);
        if (r.indexOf(ch) == -1)              // not seen before: keep it
            r = r + ch;
        // examine the next character
        return remvDup(s, r, i + 1);
    }

    // displays the original and the modified string
    void display()
    {
        nw = remvDup(wrd, "", 0);
        System.out.println("Original string : " + wrd);
        System.out.println("String after removing duplicate characters : "
                           + nw);
    }

    public static void main(String args[])
    {
        Duplicate ob = new Duplicate();
        ob.acceptword();
        ob.display();
    }
}

  • r.indexOf(ch) == -1 means ch is not yet in r.
  • A recursive string method: base case at the end of the string; each call handles one character and recurses on i + 1.

[The second output line, 673, is printed at the top of the next page in the original. It is the odd-positioned digits of 65723 (1st, 3rd and 5th: 6, 7, 3) — the second thing show() displays. The closing instruction's “Join(Join X, Join Y)” means the method JoinNum(Join X, Join Y).]

Answer

Idea: appending the digits of Y to X numerically means shifting X left by as many decimal places as Y has digits: \(65 \times 10^3 + 723 = 65723\). The digits of Y are counted with a loop (a do–while, so that 0 counts as one digit). For the odd positions (counted from the left: 1st, 3rd, 5th …) the digits are peeled from the right while the position is counted down from the total number of digits.

import java.util.Scanner;

public class Join
{
    int num;                     // the number
    // one Scanner shared by all objects
    static Scanner sc = new Scanner(System.in);

    // constructor: legal initial value
    Join()
    {
        num = 0;
    }

    // accepts the number
    void readNumber()
    {
        System.out.println("Enter a number :");
        num = sc.nextInt();
    }

    /* Joins X.num and Y.num numerically: X.num is shifted left by
       as many decimal places as Y.num has digits, then Y.num is added.
       e.g. 65 and 723 : 65 * 1000 + 723 = 65723 */
    Join JoinNum(Join X, Join Y)
    {
        // 10 ^ (number of digits of Y.num)
        int p = 1;
        int t = Y.num;
        do
        {
            p = p * 10;
            t = t / 10;
        // do-while: 0 still counts as one digit
        } while (t > 0);
        Join R = new Join();
        R.num = X.num * p + Y.num;
        return R;
    }

    // shows the merged number and its odd-positioned digits (from left)
    void show()
    {
        System.out.println("Merged number : " + num);
        int d = 0, t = num;
        do                               // count the digits
        {
            d++;
            t = t / 10;
        } while (t > 0);
        // odd-positioned digits, kept in order
        int odd = 0, p = 1;
        t = num;
        // rightmost digit is position d
        for (int pos = d; pos >= 1; pos--)
        {
            int dig = t % 10;
            t = t / 10;
            if (pos % 2 == 1)
            {
                odd = odd + dig * p;
                p = p * 10;
            }
        }
        System.out.println("Odd positioned digits : " + odd);
    }

    public static void main(String args[])
    {
        Join a = new Join();
        Join b = new Join();
        a.readNumber();
        b.readNumber();
        Join c = new Join();
        c = c.JoinNum(a, b);
        c.show();
    }
}

[As printed, the member table gives element_k() the return type void although it “returns” the element, and the closing instruction says int element_k(); it is written here as int element_k(). “store in mat” means the array arr[][]. The order is called N×M in the first line but M is the number of rows in the table; the table is followed.]

Answer

Idea: keep four boundaries — top, bottom, left, right. Go along the top row (left → right), down the right column, back along the bottom row (right → left), up the left column; then move each boundary one step inwards and repeat. Count elements as they are visited and return the one at count k.

import java.util.Scanner;

public class Swirl
{
    int arr[][];     // the matrix
    int M;           // number of rows
    int N;           // number of columns
    int k;           // position wanted in the spiral order

    // constructor: legal initial values
    Swirl()
    {
        M = 0;
        N = 0;
        k = 0;
        arr = new int[1][1];
    }

    // accepts the order, the elements and k
    void read()
    {
        Scanner sc = new Scanner(System.in);
        System.out.println("Enter the number of rows and columns :");
        M = sc.nextInt();
        N = sc.nextInt();
        arr = new int[M][N];
        System.out.println("Enter the elements row by row :");
        for (int i = 0; i < M; i++)
            for (int j = 0; j < N; j++)
                arr[i][j] = sc.nextInt();
        System.out.println("Enter k :");
        k = sc.nextInt();
    }

    /* Walks the matrix in spiral order - top row left to right, right
       column downwards, bottom row right to left, left column upwards -
       then moves the four boundaries inwards, counting elements
       until the k-th. */
    int element_k()
    {
        int top = 0, bottom = M - 1, left = 0, right = N - 1;
        int count = 0;
        while (top <= bottom && left <= right)
        {
            for (int j = left; j <= right; j++)            // top row
                if (++count == k) return arr[top][j];
            top++;
            for (int i = top; i <= bottom; i++)            // right column
                if (++count == k) return arr[i][right];
            right--;
            if (top <= bottom)
            {
                for (int j = right; j >= left; j--)        // bottom row
                    if (++count == k) return arr[bottom][j];
                bottom--;
            }
            if (left <= right)
            {
                for (int i = bottom; i >= top; i--)        // left column
                    if (++count == k) return arr[i][left];
                left++;
            }
        }
        // k out of range
        return -1;
    }

    // displays the k-th element
    void show()
    {
        if (k < 1 || k > M * N)
        {
            System.out.println("Invalid k : the matrix has only "
                               + (M * N) + " elements");
            return;
        }
        System.out.println("Element number " + k + " in spiral order = "
                           + element_k());
    }

    public static void main(String args[])
    {
        Swirl ob = new Swirl();
        ob.read();
        ob.show();
    }
}

Q9Data structures — single linked list (deletion)[5]

A linked list is formed from the objects of the class Node. The details of the class Node is as follows:

Class Node
{
String str;
Node link;}

Write an algorithm OR a Method to delete the start/first node containing str of an existing linked list. The prototype of the method is : void deleteNode(Node first)

Answer

“The start/first node” is the node first refers to. Java passes the reference first by value, so the method cannot make the caller's start variable point to the second node. Instead it removes the first node's contents: the second node's data is copied into the first node and the second node is unlinked. The list seen from the caller's start reference is then the old list without its first element.

Algorithm

  1. Start.
  2. If first = null, display “List is empty” and stop.
  3. If first.link = null (only one node), clear first.str and report that the caller must set start = null; stop.
  4. second ← first.link.
  5. first.str ← second.str.
  6. first.link ← second.link.
  7. second.link ← null.
  8. Stop.

Method

void deleteNode(Node first)
{
    if (first == null)                  // nothing to delete
    {
        System.out.println("List is empty");
        return;
    }
    if (first.link == null)             // only one node in the list:
    {                                   // clear it; the caller must
        first.str = null;               // then set start = null
        System.out.println("Only node removed: set start = null");
        return;
    }
    Node second = first.link;           // the node after the start node
    first.str = second.str;             // copy its data into the start
    first.link = second.link;           // and bypass the second node
    second.link = null;                 // detach the removed node
}

Green -> Blue -> Pink -> null

If the list's start is a data member of the list class (as in most ISC programs), the usual answer is simply if (start != null) start = start.link; — the method here keeps to the printed prototype.

Concepts to recall

  • Deleting the first node of a list: start = start.link (O(1)).
  • Object references are passed by value: a method can change the object's fields but not the caller's variable.
  • Always handle the empty list and the one-node list.
Q10(a)Data structures — binary trees[2]

Is binary tree a recursive data structure? Justify your answer.

Answer

Yes. A binary tree is defined in terms of itself: it is either empty, or it consists of a root node together with a left subtree and a right subtree, each of which is again a binary tree. Because of this, operations on it (traversals, counting nodes, height) are written naturally as recursive methods — e.g. size(T) = 1 + size(left) + size(right), with size(empty) = 0 as the base case.

Concepts to recall

  • Recursive definition: empty, or root + left binary tree + right binary tree.
  • Pre/in/post-order traversals are recursive.

The interface carries only the method prototype (an interface has no instance data members — any variable in it is a public static final constant). Worker implements Staff; Wages extends Worker, so it is also a Staff, and its constructor passes the name and basic pay to the superclass with super(…).

interface Staff
{
    // no instance data in an interface; the method is public and abstract
    void display();
}

class Worker implements Staff
{
    protected String name;      // name of the worker
    protected double basic;     // basic pay

    Worker(String ns, double bs)
    {
        name = ns;
        basic = bs;
    }

    public void display()
    {
        System.out.println("Name        : " + name);
        System.out.println("Basic pay   : " + basic);
    }
}

// Wages also implements Staff, through Worker
class Wages extends Worker
{
    int hours;                  // hours worked
    double rate;                // rate per hour
    double wage;                // overall wages

    Wages(String ns, double bs, int h, double r)
    {
        super(ns, bs);          // super class members first
        hours = h;
        rate = r;
        wage = 0.0;
    }

    double overtime()
    {
        return hours * rate;
    }

    public void display()
    {
        wage = overtime() + basic;
        super.display();        // name and basic pay
        System.out.println("Hours       : " + hours);
        System.out.println("Rate        : " + rate);
        System.out.println("Overtime    : " + overtime());
        System.out.println("Total wages : " + wage);
    }
}
