QUESTION 1

A Prime-Adam integer is a positive integer (without leading zeros) which is a prime as well as an Adam number.

Prime number: A number which has only two factors, i.e. 1 and the number itself.
Example: 2, 3, 5, 7 ... etc.

Adam number: The square of a number and the square of its reverse are reverse to each other.
Example: If n = 13 and reverse of 'n' = 31, then,
(13)2 = 169
(31)2 = 961 which is reverse of 169
thus 13, is an Adam number.

Accept two positive integers m and n, where m is less than n as user input. Display all Prime-Adam integers that are in the range between m and n (both inclusive) and output them along with the frequency, in the format given below:

Answer

Answer as the practical expects it: the algorithm, then the documented Java program, then the output for the paper's examples and for further inputs — every output below is from an actual run of this program (JDK 11). The input given to each run is shown above its output.

Idea. Test each i from m to n: i must be prime (no divisor from 2 to √i) and Adam (reverse(i²) = (reverse(i))², e.g. 12: 144 reversed is 441 = 21²). The squares are held in long so that large ranges do not overflow. m ≥ n (or a non-positive limit) is invalid.

Algorithm

  1. Start. Input m and n.
  2. If m ≤ 0 or n ≤ 0 or m ≥ n, print “INVALID INPUT” and stop.
  3. freq ← 0, list ← "".
  4. For i = m to n: if isPrime(i) and isAdam(i), append i to list and freq ← freq + 1.
  5. Print “THE PRIME-ADAM INTEGERS ARE:”; print “NIL” if freq = 0, else print list.
  6. Print “FREQUENCY OF PRIME-ADAM INTEGERS IS: ” freq. Stop.

isPrime(x): if x < 2 return false; for d = 2 while d × d ≤ x: if x mod d = 0 return false; return true.
reverse(x): r ← 0; while x > 0: r ← r × 10 + x mod 10, x ← x div 10; return r.
isAdam(x): return reverse(x × x) = reverse(x) × reverse(x).

Program

import java.util.Scanner;

public class PrimeAdam
{
    // true if n has exactly two factors, 1 and n
    static boolean isPrime(int n)
    {
        if (n < 2)
            return false;
        for (int i = 2; i * i <= n; i++)
            if (n % i == 0)
                return false;
        return true;
    }

    // the digits of n in reverse order
    static long reverse(long n)
    {
        long r = 0;
        while (n > 0)
        {
            r = r * 10 + n % 10;
            n = n / 10;
        }
        return r;
    }

    // Adam: square of the reverse of n = reverse of the square of n
    static boolean isAdam(int n)
    {
        long sq = (long) n * n;
        long rn = reverse(n);
        long sqr = rn * rn;
        return sqr == reverse(sq);
    }

    public static void main(String args[])
    {
        Scanner sc = new Scanner(System.in);
        int m = sc.nextInt();                        // lower limit
        int n = sc.nextInt();                        // upper limit
        // m must be less than n
        if (m <= 0 || n <= 0 || m >= n)
        {
            System.out.println("INVALID INPUT");
            return;
        }
        // number of Prime-Adam integers found
        int freq = 0;
        // the integers found, space separated
        String list = "";
        for (int i = m; i <= n; i++)
        {
            if (isPrime(i) && isAdam(i))
            {
                list = list + i + " ";
                freq++;
            }
        }
        System.out.println("THE PRIME-ADAM INTEGERS ARE:");
        if (freq == 0)
            System.out.println("NIL");
        else
            System.out.println(list.trim());
        System.out.println("FREQUENCY OF PRIME-ADAM INTEGERS IS: "
                           + freq);
    }
}

Answer

Answer as the practical expects it: the algorithm, then the documented Java program, then the output for the paper's examples and for further inputs — every output below is from an actual run of this program (JDK 11). The input given to each run is shown above its output.

Idea. Shifting every column one step right is a right rotation of each row: the last element of a row is saved, the others move one place right, and the saved element goes into column 0 (as in both examples, the last column comes round to the first). The second smallest element is the smallest value greater than the minimum (a repeated minimum is not counted twice); its first position in the shifted matrix, row by row, is reported with 0-based row and column numbers as in the examples.

Algorithm

  1. Start. Input M and N. If M ≤ 2 or M ≥ 10 or N ≤ 2 or N ≥ 10, print “Size is out of Range. Invalid Entry” and stop.
  2. Input the M × N elements into A[][]; display A.
  3. For each row i: last ← A[i][N−1]; for j = N−1 down to 1: A[i][j] ← A[i][j−1]; A[i][0] ← last.
  4. Display A with the heading “Formed matrix after shifting”.
  5. min ← the smallest element of A.
  6. sec ← the smallest element of A that is greater than min, scanning row by row; record its row r and column c.
  7. If no element exceeds min, report that there is no second smallest element; otherwise print “Second Smallest Element : sec (Row: r and Column: c)”. Stop.

Program

import java.util.Scanner;

public class ShiftMatrix
{
    int A[][];      // the matrix
    int M, N;       // rows and columns

    ShiftMatrix(int m, int n)
    {
        M = m;
        N = n;
        A = new int[M][N];
    }

    void input(Scanner sc)
    {
        System.out.println("Enter the elements in the matrix:");
        for (int i = 0; i < M; i++)
            for (int j = 0; j < N; j++)
                A[i][j] = sc.nextInt();
    }

    void display(String msg)
    {
        System.out.println(msg);
        for (int i = 0; i < M; i++)
        {
            for (int j = 0; j < N; j++)
                System.out.printf("%6d", A[i][j]);
            System.out.println();
        }
    }

    // each column moves one step right; the last comes round to the first
    void shift()
    {
        for (int i = 0; i < M; i++)
        {
            int last = A[i][N - 1];
            for (int j = N - 1; j > 0; j--)
                A[i][j] = A[i][j - 1];
            A[i][0] = last;
        }
    }

    /* second smallest DISTINCT value and its location (first occurrence,
       scanning row by row) in the shifted matrix */
    void secondSmallest()
    {
        int min = A[0][0];
        for (int i = 0; i < M; i++)
            for (int j = 0; j < N; j++)
                if (A[i][j] < min)
                    min = A[i][j];
        boolean found = false;
        int sec = 0, r = -1, c = -1;
        for (int i = 0; i < M; i++)
            for (int j = 0; j < N; j++)
                if (A[i][j] > min && (!found || A[i][j] < sec))
                {
                    sec = A[i][j];
                    r = i;
                    c = j;
                    found = true;
                }
        if (!found)
            System.out.println("No second smallest element: "
                               + "all elements are equal");
        else
            System.out.println("Second Smallest Element : " + sec
                               + " (Row: " + r + " and Column: " + c
                               + ")");
    }

    public static void main(String args[])
    {
        Scanner sc = new Scanner(System.in);
        System.out.print("M = ");
        int m = sc.nextInt();
        System.out.println(m);
        System.out.print("N = ");
        int n = sc.nextInt();
        System.out.println(n);
        if (m <= 2 || m >= 10 || n <= 2 || n >= 10)
        {
            System.out.println("Size is out of Range. Invalid Entry");
            return;
        }
        ShiftMatrix ob = new ShiftMatrix(m, n);
        ob.input(sc);
        ob.display("Input matrix");
        ob.shift();
        ob.display("Formed matrix after shifting");
        ob.secondSmallest();
    }
}

Answer

Answer as the practical expects it: the algorithm, then the documented Java program, then the output for the paper's examples and for further inputs — every output below is from an actual run of this program (JDK 11). The input given to each run is shown above its output.

Idea. A letter on key d needs as many presses as its position on that key (A = 1 press of 2, B = 2, C = 3; S = 4 presses of 7). For each word the presses are added per key, and the keys are listed in the order in which they are first used in that word (this reproduces both sample outputs: in ALL the two Ls add 3 + 3 = 6 presses of key 5). Between two words the program prints “White Space” and one press of key 0. The sentence may contain only letters and single spaces; anything else (such as the hyphen in GOOD-LUCK) is invalid. Lower-case input is converted to capitals.

Algorithm

  1. Start. Input the sentence s; s ← s trimmed and in upper case.
  2. If s is empty, or contains a character that is neither a letter nor a space, or two consecutive spaces, print “Invalid Entry” and stop.
  3. Split s into words at the spaces.
  4. For each word w (index i): if i > 0 print “White Space” and “Number 0 is pressed 1 time.”; print w.
  5.   Set count[0…9] ← 0 and an empty list order. For each letter ch of w: d ← the key carrying ch; if count[d] = 0 add d to order; count[d] ← count[d] + (position of ch on key d).
  6.   For each d in order print “Number d is pressed count[d] time(s)”.
  7. Stop.

Program

import java.util.Scanner;

public class Keypad
{
    // letters on keys 2 to 9; KEYS[d - 2] holds the letters on key d
    static final String KEYS[] = {"ABC", "DEF", "GHI", "JKL",
                                  "MNO", "PQRS", "TUV", "WXYZ"};

    // the key that carries letter ch
    static int key(char ch)
    {
        for (int d = 0; d < KEYS.length; d++)
            if (KEYS[d].indexOf(ch) >= 0)
                return d + 2;
        return -1;
    }

    // presses needed for ch: its position on its key, counting from 1
    static int presses(char ch)
    {
        return KEYS[key(ch) - 2].indexOf(ch) + 1;
    }

    static String times(int n)
    {
        return n == 1 ? "1 time" : n + " times";
    }

    /* prints, for one word, every key used and the total presses on it,
       keys listed in the order they are first used */
    static void word(String w)
    {
        System.out.println(w);
        int count[] = new int[10];      // presses per key 0..9
        int order[] = new int[10];      // keys in order of first use
        int k = 0;
        for (int i = 0; i < w.length(); i++)
        {
            char ch = w.charAt(i);
            int d = key(ch);
            if (count[d] == 0)
                order[k++] = d;
            count[d] += presses(ch);
        }
        for (int i = 0; i < k; i++)
            System.out.println("Number " + order[i] + " is pressed "
                               + times(count[order[i]]));
    }

    public static void main(String args[])
    {
        Scanner sc = new Scanner(System.in);
        String s = sc.nextLine().trim().toUpperCase();
        // only letters and single spaces between words are allowed
        boolean ok = s.length() > 0;
        for (int i = 0; i < s.length() && ok; i++)
        {
            char ch = s.charAt(i);
            if (!(Character.isLetter(ch) || ch == ' '))
                ok = false;
            if (ch == ' ' && s.charAt(i + 1) == ' ')
                ok = false;
        }
        if (!ok)
        {
            System.out.println("Invalid Entry");
            return;
        }
        String w[] = s.split(" ");
        for (int i = 0; i < w.length; i++)
        {
            if (i > 0)
            {
                System.out.println("White Space");
                System.out.println("Number 0 is pressed 1 time.");
            }
            word(w[i]);
        }
    }
}
