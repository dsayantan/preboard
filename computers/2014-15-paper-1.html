Q1(b)Boolean Algebra (propositional logic)[2]

If \(X \Rightarrow Y\) then write its
i. Converse
ii. Contra positive

Answer

i. Converse (swap the two parts): \(Y \Rightarrow X\)

ii. Contrapositive (swap and negate both): \(\sim Y \Rightarrow \sim X\) (i.e. \(Y' \Rightarrow X'\)), which is logically equivalent to \(X \Rightarrow Y\).

Concepts to recall

  • Converse: \(q\Rightarrow p\). Inverse: \(\sim p\Rightarrow\sim q\). Contrapositive: \(\sim q\Rightarrow\sim p\).
  • Only the contrapositive is equivalent to the original.
Q1(c)Computer Hardware (universal gates)[2]

Show how NAND gates can be used to construct an OR gate.

Answer

Invert A and B with NAND gates whose inputs are tied, then NAND the results:

\(\overline{A\cdot A} = A'\), \(\overline{B\cdot B}=B'\), and \(\overline{A'\cdot B'} = A'' + B'' = A + B\) (De Morgan).

Concepts to recall

  • NOT from NAND: tie the inputs.
  • De Morgan: \((A'B')' = A+B\).
Q1(d)Boolean Algebra[2]

Given \(F(X,Y,Z)=X.Y'+XZ+Z'\) write the function is canonical sum- of – product form.

Answer

Multiply each term by \((V+V')\) for every missing variable V:

\[\begin{aligned} XY' &= XY'(Z+Z') = XY'Z + XY'Z'\\ XZ &= XZ(Y+Y') = XYZ + XY'Z\\ Z' &= Z'(X+X')(Y+Y') = XYZ' + XY'Z' + X'YZ' + X'Y'Z' \end{aligned}\]

Removing repeated terms (\(P+P=P\)):

\(F = X'Y'Z' + X'YZ' + XY'Z' + XY'Z + XYZ' + XYZ = \sum(0,2,4,5,6,7)\)

Concepts to recall

  • Canonical SOP: every term contains every variable.
  • Expand with \(V+V'=1\); drop duplicates (idempotence).

Q2(c)Arrays (address calculation)[2]

A matrix B[10][7] is stored in the memory with each element requiring 2 bytes of storage. If the base address at B[X][1] is 1012 and the base address at B[7][3] is 1060, determine the value ‘X’ where the matrix is stored in column major form.

Answer

Column-major, number of rows \(M = 10\), \(W = 2\): \(\text{Address}(B[I][J]) = B_0 + W[(I-L_r) + M(J-L_c)]\). Subtracting the two given addresses removes the unknown base and lower bounds:

\[1060 - 1012 = 2\,[\,(7 - X) + 10(3 - 1)\,]\]

\[48 = 2\,[\,27 - X\,] \;\Rightarrow\; 27 - X = 24 \;\Rightarrow\; X = 3\]

X = 3

Check (indices from 0): \(B_0 = 1060 - 2(7+30) = 986\), and \(B[3][1] = 986 + 2(3+10) = 1012\). ✓

Concepts to recall

  • Column-major: \(B + W[(I-L_r)+M(J-L_c)]\), M = number of rows.
  • Two known addresses: subtract to eliminate the base.
Q2(d)Complexity and Big O notation[2]

What do you mean by dominant term in Complexity? Support with an example.

Answer

The dominant term is the term in the expression for an algorithm's running time that grows fastest as the input size n increases; for large n it decides the time, so the complexity is written using that term alone (constant factors dropped).

Example: a method performs \(T(n) = 3n^2 + 5n + 20\) steps (a nested loop plus a single loop). For \(n = 1000\): \(3n^2 = 3\,000\,000\) while \(5n + 20 = 5020\). The dominant term is \(3n^2\), so \(T(n) = O(n^2)\).

Concepts to recall

  • Growth order: \(1 < \log n < n < n\log n < n^2 < 2^n\).
  • Big O keeps only the dominant term, without its constant.

Q8Recursion[10]

A class called DigiNumber has been defined to find the frequency of each digit present in a number and the sum of the digits. Some of the members of the class DigiNumber are given below:

Class name : DigiNumber
Data members/instance variables :
num : long integer for storing the number
Member functions :
DigiNumber ( ) : constructor to assign 0 to num
DigiNumber (long n) : parameterised constructor to assign n to num
void digitfrequency( ) : find the frequency of each digit present in num and to display it
long sumDigits(long N) : to return the sum of the digits of the number stored in num using Recursive Technique
void printsum( ) : print sum of digits of num by invoking sumDigits(…)

Specify the class DigiNumber, giving details of the two Constructor and functions void digitfrequency( ), long sumDigits(long) and void printsum( ). Also write the main( ) function to create an object and call the member function accordingly.

Answer

Logic: a frequency array freq[10] is filled by peeling digits with % 10 and / 10; sumDigits(N) = N%10 + sumDigits(N/10) with base case N = 0.

import java.util.Scanner;

class DigiNumber {
    long num;                               // the number

    DigiNumber() {                          // default constructor
        num = 0;
    }

    // parameterised constructor
    DigiNumber(long n) {
        num = n;
    }

    // frequency of each digit present in num
    void digitfrequency() {
        int freq[] = new int[10];
        long t = Math.abs(num);
        if (t == 0)
            freq[0] = 1;
        while (t > 0) {
            freq[(int) (t % 10)]++;
            t /= 10;
        }
        System.out.println("Digit\tFrequency");
        for (int d = 0; d <= 9; d++)
            if (freq[d] > 0)
                System.out.println(d + "\t" + freq[d]);
    }

    // recursive sum of digits
    long sumDigits(long N) {
        if (N == 0)                         // base case
            return 0;
        return N % 10 + sumDigits(N / 10);
    }

    void printsum() {
        System.out.println("Sum of digits of " + num + " = "
                           + sumDigits(Math.abs(num)));
    }

    public static void main(String args[]) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter a number: ");
        DigiNumber ob = new DigiNumber(sc.nextLong());
        ob.digitfrequency();
        ob.printsum();
    }
}

Sample input

1225532

Output (the typed input is not echoed)

Enter a number: Digit	Frequency
1	1
2	3
3	1
5	2
Sum of digits of 1225532 = 20

Concepts to recall

  • Last digit n % 10, remove it n / 10.
  • Recursive sum: \(s(N) = N\%10 + s(N/10)\), \(s(0)=0\).
  • Overloaded constructors differ in their parameter lists.
Q9Objects (passing and returning objects)[10]

Following is the description of class Collection:

Class name : Collection
Data members/ instance variables:
arr[] : an array of 100 integers.
len : length of the array
Member functions/methods:
Collection( ) : default constructor
Collection(int) : parameterised constructor to define the length of the array.
void readArray( ) : to accept array elements.
Collection common(Collection) : this function will receive an object of Collection. Then, it will find the common elements in its own array and in the array of the object received. Finally it will return the common elements as an array of the Collection object.
void displayArray( ) : to display the array elements .

Specify the class Collection giving the details of the constructors and the given methods. You need not write the main() method.

Answer

Logic: for each element of this array, search the other object's array; if found and not already in the result, append it to a new Collection whose len counts the elements added. The result object is returned.

import java.util.Scanner;

class Collection {
    int arr[];                          // the elements
    // number of elements in use
    int len;
    static Scanner sc = new Scanner(System.in);

    Collection() {                      // default constructor
        arr = new int[100];
        len = 0;
    }

    // array of length n (at most 100)
    Collection(int n) {
        arr = new int[100];
        len = Math.min(n, 100);
    }

    void readArray() {
        System.out.println("Enter " + len + " integers:");
        for (int i = 0; i < len; i++)
            arr[i] = sc.nextInt();
    }

    // elements in both this array and ob's
    Collection common(Collection ob) {
        Collection res = new Collection();
        for (int i = 0; i < len; i++) {
            boolean inOther = false, already = false;
            for (int j = 0; j < ob.len; j++)
                if (arr[i] == ob.arr[j]) {
                    inOther = true;
                    break;
                }
            // keep each common value once
            for (int k = 0; k < res.len; k++)
                if (res.arr[k] == arr[i]) {
                    already = true;
                    break;
                }
            if (inOther && !already)
                res.arr[res.len++] = arr[i];
        }
        return res;
    }

    void displayArray() {
        for (int i = 0; i < len; i++)
            System.out.print(arr[i] + " ");
        System.out.println();
    }
}

Write a java program to input a paragraph from the user and then follow the class definition as given below.

Class name : Maxword_paragraph
Data members/ instance variables:
sent : stores the paragraph. The paragraph should consist of 5-sentences only, and Should either end with a full stop (.) or an exclamation mark ( ! ).
rem [5][n] : to store the each of the sentences in the paragraph in each of the rows. Extract each word and place it in each of the cells for a particular row, for each of the sentence. When n represents the number of words of the longest sentence.
Member functions/methods:
void readparagraph( ) : to accept the paragraph with the given constraints in sent.
void para_to_array( ) : extract each word of a sentence and store it in rem[][]. And each row of rem[][] represents a sentence. Fill the blank cells of rem[][]with “Q”. Display the array.
void word_max() : to find and print the word with the maximum length and print its position as stored in the rem[][].

Specify the class Maxword_paragraph giving details of all the methods and the constructor. Create an object in main () and call the above methods.

Answer

Logic: validate that the paragraph has exactly five terminators ('.' or '!') and ends with one; split it into sentences with a StringTokenizer on ".!"; n = the largest word count; fill each row of rem with that sentence's words and pad with "Q"; then scan the array for the longest word (the first one found wins a tie).

import java.util.Scanner;
import java.util.StringTokenizer;

class Maxword_paragraph {
    String sent;                     // the paragraph
    // rem[5][n]: one sentence per row, one word per cell
    String rem[][];

    Maxword_paragraph() {
        sent = "";
    }

    // accept a paragraph of exactly 5 sentences
    void readparagraph() {
        Scanner sc = new Scanner(System.in);
        while (true) {
            System.out.println("Enter 5 sentences, each ending in . or !");
            sent = sc.nextLine().trim();
            int count = 0;
            for (int i = 0; i < sent.length(); i++) {
                char ch = sent.charAt(i);
                if (ch == '.' || ch == '!')
                    count++;
            }
            int L = sent.length();
            char last = (L > 0) ? sent.charAt(L - 1) : ' ';
            if (count == 5 && (last == '.' || last == '!'))
                break;
            System.out.println("INVALID INPUT");
        }
    }

    void para_to_array() {
        StringTokenizer st = new StringTokenizer(sent, ".!");
        String s[] = new String[5];
        // words in the longest sentence
        int n = 0;
        for (int r = 0; r < 5; r++) {
            s[r] = st.nextToken().trim();
            n = Math.max(n, new StringTokenizer(s[r], " ,;:?").countTokens());
        }
        rem = new String[5][n];
        for (int r = 0; r < 5; r++) {
            StringTokenizer w = new StringTokenizer(s[r], " ,;:?");
            for (int c = 0; c < n; c++)
                // blank cells get "Q"
                rem[r][c] = w.hasMoreTokens() ? w.nextToken() : "Q";
        }
        // display the array
        for (int r = 0; r < 5; r++) {
            for (int c = 0; c < n; c++)
                System.out.print(rem[r][c] + "\t");
            System.out.println();
        }
    }

    // longest word and where it is stored
    void word_max() {
        int mr = 0, mc = 0;
        for (int r = 0; r < rem.length; r++)
            for (int c = 0; c < rem[r].length; c++)
                if (!rem[r][c].equals("Q")
                        && rem[r][c].length() > rem[mr][mc].length()) {
                    mr = r;
                    mc = c;
                }
        System.out.println("Longest word: " + rem[mr][mc]
                + " at rem[" + mr + "][" + mc + "]");
    }

    public static void main(String args[]) {
        Maxword_paragraph ob = new Maxword_paragraph();
        ob.readparagraph();
        ob.para_to_array();
        ob.word_max();
    }
}

Sample input

Hello there.
The cat sat on the mat. I love Java! It is a programming language. Hello world! Computers are wonderful machines.

Output (the typed input is not echoed)

Enter 5 sentences, each ending in . or !
INVALID INPUT
Enter 5 sentences, each ending in . or !

I	love	Java	Q	Q	Q	
It	is	a	programming	language	Q	
Hello	world	Q	Q	Q	Q	
Computers	are	wonderful	machines	Q	Q	
Longest word: programming at rem[2][3]

Concepts to recall

  • StringTokenizer(s, delims) and countTokens().
  • A 2-D array can be created after its size is known: new String[5][n].
  • Track the row and column of the current maximum.

Q11Inheritance, Interfaces and Polymorphism[10]

A class salesman defines the personal data of a salesman, while another class Sales defines the bill number, name of the item, and number of items sold and the price of the item. The details of the classes are as follows:

Class name : Salesman
Data members/ instance variables :
name : String variable to store the name of the salesman
address : String variable to store the address
Member functions/methods :
Salesman(String n, String ad ) : parameterised constructor to assign ‘n’ and ‘a’ to name and address respectively.
void show( ) : to print the values of name and address using suitable headings

Class name : Sales
Data members/ instance variables:
billno, qty : Integer to store bill number and quantity
price, psales : Double type to store price and previous sales amount
pname : String variable to store name of product
Member functions/methods:
Sales( ….. ) : parameterised constructor to call the constructor of the base class and to assign ‘b’ to billno,‘q’ to qty,‘p’ to price, ‘s’ to psales and ‘pr’ to pname of the derived class.
double calculate( ) : to calculate and return the total sales using the formula: price*qty + psales
void show( ) : to display values of pname, billno, qty, psales and the total sales made by invoking suitable functions and also call the display( ) method of the super class.

Specify the class Salesman giving the details of the constructor and the functions. Using the concept of Inheritance specify the class Sales giving the details of the functions. You do not need to write the main( ) method.

Answer

The superclass method is named show() in its description, so “the display( ) method of the super class” is super.show().

Sales extends Salesman; its constructor passes n and ad to super(n, ad) as its first statement, and its show() overrides the superclass one and calls it through super.

class Salesman {
    String name, address;

    Salesman(String n, String ad) {
        name = n;
        address = ad;
    }

    void show() {
        System.out.println("Name of salesman : " + name);
        System.out.println("Address          : " + address);
    }
}

class Sales extends Salesman {
    int billno, qty;
    double price, psales;
    String pname;

    Sales(String n, String ad, int b, int q,
          double p, double s, String pr) {
        // constructor of the base class first
        super(n, ad);
        billno = b;
        qty = q;
        price = p;
        psales = s;
        pname = pr;
    }

    double calculate() {
        return price * qty + psales;  // total sales
    }

    void show() {                     // overrides Salesman.show()
        // display of the super class
        super.show();
        System.out.println("Product          : " + pname);
        System.out.println("Bill number      : " + billno);
        System.out.println("Quantity         : " + qty);
        System.out.println("Previous sales   : " + psales);
        System.out.println("Total sales      : " + calculate());
    }
}

Test: new Sales("R. Sen", "Kolkata", 101, 5, 250.0, 1200.0, "Pen drive").show(); (total = 250×5 + 1200 = 2450)

Output

Name of salesman : R. Sen
Address          : Kolkata
Product          : Pen drive
Bill number      : 101
Quantity         : 5
Previous sales   : 1200.0
Total sales      : 2450.0

Concepts to recall

  • super(args) must be the first statement of the subclass constructor.
  • An overriding method calls the parent version with super.show().
Q12Data Structures (queue, dequeue)[10]

A special type of queue enables the user to add integers from either ends, i.e. from front and rear, but allows removal only from the front end. Define the class Squeue with the following details:

Class name : Squeue
Data members/ instance variables:
que[] : array to hold up to 100 integers
lim : stores the limit of the circular queue.
front : integer to point to the front end index number
rear : integer to point to the rear end index number
Member functions/methods:
Squeue (int l) : constructor to initialize the data members lim=l, front=rear=0
void insert(int val ) : to add integers to the special queue from both the ends –

  • Firstly ask the user to choose , at which end the user wants to enter the data
  • If the user chooses front and queue is not full then shift the elements to the right by one place and then enter the element at the front. If front – most position is empty then insert the data there and point it as front.
  • Now, if the user wants to enter the data at the rear position then follow the same algorithm as a normal queue.
  • If the array is filled up and you cannot enter any more data then print “OVERFLOW”.

int delete( ) : returns element from front, if possible, otherwise returns the value -9999.

Specify the class Squeue giving the details of the constructor and the functions. Using the concept of Inheritance specify the class Sales giving the details of the functions. You do not need to write the main( ) method.

Answer

The last sentence (“Using the concept of Inheritance specify the class Sales”) is carried over from Question 11 by mistake; only class Squeue is asked for.

Representation: the elements are que[front] … que[rear-1]; front = rear means empty. Insertion at the rear needs rear < lim. Insertion at the front uses the free cell before front if there is one; otherwise, if the array is not full, every element is shifted one place right and the new value goes in at front.

import java.util.Scanner;

class Squeue {
    int que[] = new int[100];
    // elements are que[front] .. que[rear-1]
    int lim, front, rear;
    static Scanner sc = new Scanner(System.in);

    Squeue(int l) {
        lim = Math.min(l, 100);
        front = rear = 0;
    }

    void insert(int val) {
        System.out.println("Insert " + val + " at Front or Rear (F/R)?");
        char ch = Character.toUpperCase(sc.next().charAt(0));
        if (ch == 'F') {
            // front-most position is empty
            if (front > 0)
                que[--front] = val;
            // no free cell anywhere
            else if (rear == lim)
                System.out.println("OVERFLOW");
            // shift right by one, then insert
            else {
                for (int i = rear; i > front; i--)
                    que[i] = que[i - 1];
                que[front] = val;
                rear++;
            }
        // rear end: as in a normal queue
        } else {
            if (rear == lim)
                System.out.println("OVERFLOW");
            else
                que[rear++] = val;
        }
    }

    int delete() {
        if (front == rear)                       // empty
            return -9999;
        int v = que[front++];
        // became empty: reset
        if (front == rear)
            front = rear = 0;
        return v;
    }

}

Concepts to recall

  • Queue: insert at rear, delete at front (FIFO).
  • Input-restricted variant here: insert at both ends, delete at one.
  • Shift right from the rear end backwards so nothing is overwritten.
Q13(a)Data Structures (linked list)[4]

a) A linked list is formed from the objects of the class,

class Node
{
    int item;
    Node ptr;
}

Write an Algorithm or a Method to find the sum of the values of all the elements in the linked list. The method declaration is given below:
int sum(Node ptr_start)

Answer

Algorithm

  1. Start. Set S = 0 and TEMP = ptr_start.
  2. Repeat steps 3–4 while TEMP ≠ null.
  3. S = S + TEMP.item.
  4. TEMP = TEMP.ptr (move to the next node).
  5. Return S. Stop.

Method

int sum(Node ptr_start) {
    int s = 0;
    Node temp = ptr_start;          // start at the first node
    // until the end of the list
    while (temp != null) {
        s = s + temp.item;          // add this node's value
        temp = temp.ptr;            // move to the next node
    }
    return s;
}

For the list shown, sum = 12 + 7 + 25 + 4 = 48 (run output: sum = 48; an empty list gives 0).

Concepts to recall

  • Traverse with a temporary reference; never move the start reference.
  • Stop when the reference becomes null.

Q13(c)Complexity and Big O notation[2]

c) What is the worst case complexity of the following code segment:

a = a + 1
for (i = 1 ; i <= N ; i++)  {
        m = m + 2;
}
for (i = 1 ; i<= M ; i++)  {
    for (i = 1 ; i <= N ; i++)
    {
        k = k +1;
    }
}

Answer

Statement counts: \(a=a+1\) once \(\to O(1)\); first loop N times \(\to O(N)\); nested loops \(M\times N\) times \(\to O(MN)\).

Total \(= O(1) + O(N) + O(MN)\); the dominant term is \(MN\):

\(O(M\times N)\) (\(= O(N^2)\) if M = N).

The inner loop reuses i as printed; this is evidently a slip for a separate counter j, and the intended nested-loop analysis is given. (Taken literally, the inner loop leaves i = N+1 and the outer i++ makes it N+2: if M ≤ N+1 the outer loop runs only once, giving O(N) overall; if M ≥ N+2 the inner loop resets i to 1 every time and the segment never terminates.)

Concepts to recall

  • Sequential blocks: add complexities, keep the largest.
  • Nested loops: multiply the iteration counts.
