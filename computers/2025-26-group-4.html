Q1(i)Objects — static methods and variables[1]

Which statements are valid for static member methods?

I. Can access static & non-static data members.
II. Can call non-static methods.
III. Cannot refer to this or super.

(a) I & II   (b) II & III   (c) I & III   (d) Only III

Answer

A static method belongs to the class, not to any object, so it has no this; it cannot use instance (non-static) data members or call non-static methods directly (I and II are false), and it cannot refer to this or super (III is true).

(d) Only III

Concepts to recall

  • static = one copy per class, exists without any object.
  • A static method can directly use only static members; instance members need an object reference.
  • this/super refer to the current object — none exists in a static context.
Q1(ii)Recursion[1]

If binary search uses recursion instead of iteration, which of the following is valid?

i. It will contain two base cases.
ii. It will contain two recursive cases.
iii. When executed will lead to StackOverflow error.

(a) i & ii   (b) ii & iii   (c) i & iii   (d) Only iii

[The paper prints the mark [1] twice against this part; it is a single 1-mark question.]

Answer

Recursive binary search stops in two cases — the range is empty (low > high, not found) or a[mid] == key (found): two base cases. Otherwise it recurses either on the left half or on the right half: two recursive cases. The depth is only about \(\log_2 n\), so it does not overflow the stack (iii is false).

(a) i & ii

Concepts to recall

  • Base case: stops the recursion; recursive case: calls itself on a smaller problem.
  • Binary search halves the range each call — depth \(O(\log n)\).
Q1(iv)Inheritance, Interfaces and Polymorphism[1] 
interface A { void abc(); }
interface B { void abc(); }
class Check implements A, B { ... }

How many times abc() must be defined?

(a) Twice   (b) Once   (c) Compile time error   (d) Runtime error

Answer

Both interfaces declare the same signature void abc(). Interface methods carry no body, so there is no conflict: one public void abc() { … } in Check implements the method of both A and B. (Defining it twice would itself be a compile error — a duplicate method.)

(b) Once

Concepts to recall

  • A class can implement several interfaces.
  • Identical abstract signatures from two interfaces are satisfied by one method.
  • Implementing methods must be public.
Q1(v)Complexity and Big O notation[1]

Find the time complexity of:

for(i=0;i<x;i++)
   m *= Math.random();
for(j=0;j<y;j++)
   n *= Math.random();

(a) O(x)   (b) O(y)   (c) O(x+y)   (d) O(xy)

Answer

The two loops are sequential, not nested: the first runs x times, the second y times, each body \(O(1)\). Total work \(\propto x + y\); neither term dominates since x and y are independent.

(c) O(x+y)

Concepts to recall

  • Sequential blocks: add the complexities; nested loops: multiply.
  • Keep every term that depends on a different input size.
Q1(vi)Strings[1] 
System.out.println("RocKet".substring(0,4).compareTo("Rock".replace('m','o')));

Answer

Q1(viii)Propositional logic[1]

The contrapositive of \(p' \Rightarrow q\) is:

(a) \(q' \Rightarrow p\)   (b) \(q \Rightarrow p'\)   (c) \(p \Rightarrow q'\)   (d) \(q \Rightarrow p\)

Answer

Contrapositive of \(a \Rightarrow b\) is \(b' \Rightarrow a'\). With \(a = p'\), \(b = q\): \(q' \Rightarrow (p')' = q' \Rightarrow p\). (It is logically equivalent to the original — checked over all four rows.)

(a) \(q' \Rightarrow p\)

Concepts to recall

  • Converse \(b\Rightarrow a\); inverse \(a'\Rightarrow b'\); contrapositive \(b'\Rightarrow a'\).
  • Only the contrapositive is equivalent to the original statement.
  • Involution: \((p')' = p\).
Q1(ix)Complexity and Big O notation; Recursion[1]

What is the space complexity of the recursive Fibonacci function?

Answer

For fib(n) = fib(n−1) + fib(n−2) the calls are made one branch at a time, so at most n frames are on the call stack together (the chain n, n−1, …, 1). The extra memory grows linearly with n.

O(n)   (its time complexity, by contrast, is \(O(2^n)\)).

Concepts to recall

  • Space of a recursive method = maximum depth of the call stack × space per frame.
  • Do not confuse with the number of calls (time).

Define abstraction in object-oriented programming.

Answer

Abstraction is the act of representing only the essential features of an object while hiding the background details (the implementation). E.g. a user calls list.add(x) without knowing how the list stores x. In Java it is achieved through classes, abstract classes and interfaces.

Concepts to recall

  • Abstraction: show what, hide how.
  • Encapsulation: wrap data and methods together and restrict access.

Q2(ii)Arrays — address calculation[2]

A matrix \(M[-7 \ldots 12,\ 3 \ldots 20]\) is stored in memory. Each element requires 6 bytes of storage. If the base address of \(M[-7][3]\) is 2013, find the memory address of \(M[5][10]\) when the matrix is stored column-major.

Answer

Rows \(L_r = -7\) to \(U_r = 12\): number of rows \(N_r = 12 - (-7) + 1 = 20\). Columns \(L_c = 3\) to 20.

Column-major: \(\text{Address}(M[i][j]) = B + W\,[(j - L_c)\,N_r + (i - L_r)]\)

\(= 2013 + 6\,[(10 - 3)\times 20 + (5 - (-7))]\)

\(= 2013 + 6\,[140 + 12] = 2013 + 6 \times 152 = 2013 + 912\)

Address of M[5][10] = 2925

Concepts to recall

  • Column-major: \(B + W[(j-L_c)N_r + (i-L_r)]\); row-major: \(B + W[(i-L_r)N_c + (j-L_c)]\).
  • Count with \(U - L + 1\) when the lower bound is negative.

Q2(iii)(b)Recursion; Searching[1]

Q4(ii)(a)Boolean Algebra — logic circuits; Propositional logic[4]

(a) From the logic circuit diagram given below, name the outputs (1), (2) and (3) and finally derive the Boolean expression (F) and simplify it. State whether it is a tautology, contradiction or contingency.

Answer

(1) = OR of X and Y′: \(X + Y'\)
(2) = AND of X and Z: \(X\cdot Z\)
(3) = AND of (1) and (2): \((X + Y')\cdot XZ\)

\(F = (X + Y')XZ + Z'\)

\(= XXZ + XY'Z + Z'\)   (distributive)

\(= XZ + XY'Z + Z'\)   (idempotence \(XX = X\))

\(= XZ(1 + Y') + Z' = XZ + Z'\)   (absorption)

\(= (X + Z')(Z + Z') = X + Z'\)   (distributive; \(Z + Z' = 1\))

Answer

Idea: two words are anagrams exactly when their letters, sorted, give the same sequence. Equal lengths are checked first; then both arrays are sorted (bubble sort) and compared position by position.

import java.util.Scanner;

public class Anagram
{
    String s1, s2;          // the two words in lower case
    int l1, l2;             // number of characters in s1 and s2

    // parameterised constructor
    Anagram(String s1, String s2)
    {
        this.s1 = s1.toLowerCase();
        this.s2 = s2.toLowerCase();
        l1 = this.s1.length();
        l2 = this.s2.length();
    }

    // sorts c[] in ascending order (bubble sort)
    void sort(char c[])
    {
        for (int i = 0; i < c.length - 1; i++)
            for (int j = 0; j < c.length - 1 - i; j++)
                if (c[j] > c[j + 1])
                {
                    char t = c[j];
                    c[j] = c[j + 1];
                    c[j + 1] = t;
                }
    }

    // true if str1 and str2 hold the same letters
    boolean areAnagram(char[] str1, char[] str2)
    {
        if (str1.length != str2.length)
            return false;
        sort(str1);
        sort(str2);
        for (int i = 0; i < str1.length; i++)
            if (str1[i] != str2[i])
                return false;
        return true;
    }

    void check()
    {
        char a[] = s1.toCharArray();
        char b[] = s2.toCharArray();
        if (areAnagram(a, b))
            System.out.println(s1 + " and " + s2
                               + " are anagram of each other");
        else
            System.out.println(s1 + " and " + s2
                               + " are not anagram of each other");
    }

    public static void main(String args[])
    {
        Scanner sc = new Scanner(System.in);
        System.out.print("Enter first word -> ");
        String w1 = sc.next();
        System.out.print("Enter second word -> ");
        String w2 = sc.next();
        Anagram ob = new Anagram(w1, w2);
        ob.check();
    }
}

Reading the sample: the 1st and 3rd rows come out descending and the 2nd ascending, so “even” and “odd” are row positions counted from 1 (index 0 is position 1, odd). The program follows the sample. An extra array orig[][] keeps the original matrix, because display() must print both.

Insertion sort: take each element in turn as the key and shift the larger (for ascending) or smaller (for descending) elements before it one place right, then drop the key into the gap.

import java.util.Scanner;

public class Mix_sort
{
    int a[][];      // the matrix
    int m, n;       // rows, columns
    int orig[][];   // copy of the original, kept for display()
    static Scanner sc = new Scanner(System.in);

    Mix_sort(int row, int col)
    {
        m = row;
        n = col;
        a = new int[m][n];
        orig = new int[m][n];
    }

    void input()
    {
        System.out.println("Enter the array elements");
        for (int i = 0; i < m; i++)
            for (int j = 0; j < n; j++)
            {
                a[i][j] = sc.nextInt();
                orig[i][j] = a[i][j];
            }
    }

    // insertion sort, ascending
    void ascEven(int x[])
    {
        for (int i = 1; i < x.length; i++)
        {
            int key = x[i];
            int j = i - 1;
            while (j >= 0 && x[j] > key)     // shift larger elements right
            {
                x[j + 1] = x[j];
                j--;
            }
            x[j + 1] = key;
        }
    }

    // insertion sort, descending
    void dscOdd(int x[])
    {
        for (int i = 1; i < x.length; i++)
        {
            int key = x[i];
            int j = i - 1;
            while (j >= 0 && x[j] < key)     // shift smaller elements right
            {
                x[j + 1] = x[j];
                j--;
            }
            x[j + 1] = key;
        }
    }

    // rows are numbered from 1 as in the sample: rows 1, 3, 5 ... (odd
    // positions) descending, rows 2, 4, 6 ... (even positions) ascending
    void arrange()
    {
        for (int i = 0; i < m; i++)
        {
            int x[] = new int[n];
            for (int j = 0; j < n; j++)      // copy row i out
                x[j] = a[i][j];
            if ((i + 1) % 2 == 0)
                ascEven(x);
            else
                dscOdd(x);
            for (int j = 0; j < n; j++)      // store the sorted row back
                a[i][j] = x[j];
        }
    }

    void display()
    {
        System.out.println("Before sort :");
        for (int i = 0; i < m; i++)
        {
            for (int j = 0; j < n; j++)
                System.out.print(orig[i][j] + " ");
            System.out.println();
        }
        System.out.println("After sort :");
        for (int i = 0; i < m; i++)
        {
            for (int j = 0; j < n; j++)
                System.out.print(a[i][j] + " ");
            System.out.println();
        }
    }

    public static void main(String args[])
    {
        System.out.print("Row = ");
        int r = sc.nextInt();
        System.out.print("Column = ");
        int c = sc.nextInt();
        Mix_sort ob = new Mix_sort(r, c);
        ob.input();
        ob.arrange();
        ob.display();
    }
}

(a) Write the member functions void pushValue(int) and int popValue().

Answer

Insert at the rear (r moves forward), delete from the front (f moves forward). The structure is empty when f > r and full when r = cap − 1.

void pushValue(int v)
{
    if (r == cap - 1)                       // rear has reached the last cell
        System.out.println("Overflow! Insertion not possible.");
    else
    {
        r = r + 1;                          // move rear forward
        st[r] = v;                          // insert at the rear
    }
}

int popValue()
{
    if (f > r)                              // no element between front and rear
    {
        System.out.println("Underflow! Deletion not possible.");
        return -9999;
    }
    int v = st[f];                          // element at the front
    f = f + 1;                              // move front forward
    if (f > r)                              // queue became empty: reset
    {
        f = 0;
        r = -1;
    }
    return v;
}

Q11(i)Data structures — linked list[2]

A linked list is formed from the objects of the class

class Node
{
   int info;
   Node link;
}

Write an algorithm or a method to delete a node from the linked list. The method declaration is given below:

void deleteNode(Node start)

Answer

The node to delete is taken to be the one whose info equals a value read from the user.

Algorithm

  1. Read val. If start = null, print “List is empty” and stop.
  2. If start.info = val: if start.link = null (the only node) the list becomes empty — the caller sets start = null; otherwise copy start.link's info into start and set start.link = start.link.link (start itself cannot be re-pointed inside the method, as Java passes the reference by value). Stop.
  3. Set prev = start, ptr = start.link.
  4. While ptr ≠ null and ptr.info ≠ val: prev = ptr, ptr = ptr.link.
  5. If ptr = null, print “not found”; else set prev.link = ptr.link. Stop.

Method

void deleteNode(Node start)
{
    System.out.print("Enter the value to be deleted : ");
    int val = sc.nextInt();
    if (start == null)                          // empty list
    {
        System.out.println("List is empty");
        return;
    }
    if (start.info == val)                      // the first node is to go
    {
        if (start.link == null)                 // it is the only node
        {
            System.out.println("List now empty: caller sets start = null");
            return;
        }
        // start cannot be re-pointed from here (Java passes the reference
        // by value), so copy the second node into the first and unlink it
        start.info = start.link.info;
        start.link = start.link.link;
        return;
    }
    Node prev = start, ptr = start.link;    // ptr is one node ahead
    while (ptr != null && ptr.info != val)
    {
        prev = ptr;
        ptr = ptr.link;
    }
    if (ptr == null)
        System.out.println(val + " not found");
    else
        prev.link = ptr.link;               // bypass the node
}

In algorithm form ISC answers often write “start = start.link” for the first node; that is the right idea and earns the step, but inside a void method taking start as a parameter it would change only the local copy, which is why the method above copies the second node forward instead.
