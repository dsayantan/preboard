Q1(c)Boolean Algebra[1]

A sum term with a variable missing is expanded by adding \(XX' = 0\):

\(B + C' = B + C' + AA' = (A + B + C')(A' + B + C')\)

Q2(a)Variables, Expressions (final) / exceptions[2]

How is final different from finally with respect to java?

Answer

final is a modifier: a final variable is a constant (cannot be reassigned), a final method cannot be overridden, a final class cannot be extended. e.g. final double PI = 3.14159;

finally is a block used with try–catch in exception handling; the code in it is executed whether or not an exception occurs (used to release resources, close files etc.).

Concepts to recall

  • final: constant / no override / no subclass.
  • finally: always-executed block after try–catch.

Q2(c)Arrays (address calculation)[2]

Each element of an array arr[15][20] requires 'W' bytes of storage. If the address of arr[6][8] is 4550 and the base address at arr[1][1] is 4000, find the width 'W' of each cell in the array arr[][] when the array is stored in Column Major Order.

Answer

Column major: \(\text{Address}(arr[i][j]) = B + W[(i - L_r) + (j - L_c)\times N_r]\), with \(B = 4000\) at \(arr[1][1]\) (so \(L_r = L_c = 1\)) and \(N_r = 15\) rows.

\(4550 = 4000 + W[(6 - 1) + (8 - 1)\times 15]\)

\(550 = W[5 + 105] = 110\,W\)

\(W = 5\) bytes

Concepts to recall

  • Column major: \(B + W[(i-L_r) + (j-L_c)N_r]\) — multiply by the number of rows.
  • Measure i and j from the element whose address is the base.
Q2(d)Complexity and Big O notation[2]

Differentiate between worst and average case complexity.

Answer

Worst case: the maximum time (number of basic operations) an algorithm takes over all inputs of size n — an upper bound. e.g. linear search when the item is last or absent: n comparisons, O(n).

Average case: the expected time over all inputs of size n, assuming a distribution of inputs (usually all equally likely). e.g. linear search for an item present at a random position: about n/2 comparisons — still O(n).

Concepts to recall

  • Best ≤ average ≤ worst.
  • Big O drops constants: n/2 and n are both O(n).

\[\text{Sum} = 1 + \frac{x}{1!} + \frac{x^3}{2!} + \frac{x^5}{3!} + \dots + \frac{x^{2n-1}}{n!}\]

Specify the class SeriesSum giving the details of the constructor and member functions SeriesSum(int,int), void calcSeries(), int power(int,int), int factorial(int), void display() with the main() function to create an object and call the member function accordingly to enable the task.

Answer

The i-th term (i = 1 … n) is \(x^{2i-1}/i!\); the cast to double stops integer division.

import java.util.Scanner;
class SeriesSum {
    int n;          // number of terms after the leading 1
    int x;          // value of x
    double sum;     // sum of the series

    SeriesSum(int nn, int xx) {
        n = nn;
        x = xx;
        sum = 0.0;
    }

    // x raised to p, recursively: x^p = x * x^(p-1), x^0 = 1
    int power(int b, int p) {
        if (p == 0)
            return 1;
        return b * power(b, p - 1);
    }

    // m! recursively: m! = m * (m-1)!, 0! = 1! = 1
    int factorial(int m) {
        if (m <= 1)
            return 1;
        return m * factorial(m - 1);
    }

    // Sum = 1 + x/1! + x^3/2! + x^5/3! + ... + x^(2n-1)/n!
    void calcSeries() {
        sum = 1.0;
        for (int i = 1; i <= n; i++)
            sum += (double) power(x, 2 * i - 1) / factorial(i);   // i-th term
    }

    void display() {
        System.out.println("Sum of the series = " + sum);
    }

    public static void main(String args[]) {
        Scanner sc = new Scanner(System.in);
        System.out.println("Enter n: ");
        int nn = sc.nextInt();
        System.out.println("Enter x: ");
        int xx = sc.nextInt();
        SeriesSum ob = new SeriesSum(nn, xx);
        ob.calcSeries();
        ob.display();
    }
}

Q8Arrays, Strings[10]

Design a class ParagraphSort to arrange the sentences in a paragraph in decreasing order of their number of words. The sentences in the paragraph is terminated by either a full stop '.', question mark '?' or an exclamation mark '!'. Some of the data members and member functions are given below:

Data Members :
str : to store the paragraph.
lines[] : array to store the sentences separately
wrds[] : array to store number of words in each sentence

Member Functions :
void print(String lines[],int wrds[]) : to print the result along with the number of words in each sentence.
int countWords(String str) : to count the number of words in each sentence.
void sort(String lines[],int wrds[]) : to sort the paragraph in decreasing order of the number of words in each sentence.(largest sentence should be the first to appear)

Specify the class ParagraphSort giving details of all the member functions. Also write the main method to call the functions accordingly.

Answer

A constructor and a split() method (to fill lines[] and wrds[]) are added; the sort swaps a sentence together with its word count.

import java.util.Scanner;
class ParagraphSort {
    String str;         // the paragraph
    String lines[];     // the sentences, one per element
    int wrds[];         // number of words in each sentence

    ParagraphSort(String s) {
        str = s.trim();
    }

    // splits the paragraph into sentences at '.', '?' or '!'
    // and counts the words of each
    void split() {
        int count = 0;                          // number of sentences
        for (int i = 0; i < str.length(); i++) {
            char ch = str.charAt(i);
            if (ch == '.' || ch == '?' || ch == '!')
                count++;
        }
        lines = new String[count];
        wrds = new int[count];
        int k = 0, start = 0;
        for (int i = 0; i < str.length(); i++) {
            char ch = str.charAt(i);
            if (ch == '.' || ch == '?' || ch == '!') {
                lines[k] = str.substring(start, i + 1).trim();   // keep the terminator
                wrds[k] = countWords(lines[k]);
                k++;
                start = i + 1;
            }
        }
    }

    // number of words = number of blank-separated tokens
    int countWords(String s) {
        int c = 0;
        boolean inWord = false;
        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) != ' ' && !inWord) {   // a word starts here
                c++;
                inWord = true;
            } else if (s.charAt(i) == ' ')
                inWord = false;
        }
        return c;
    }

    // bubble sort in DECREASING order of word count, moving the sentence
    // together with its count; equal counts keep their original order
    void sort(String lines[], int wrds[]) {
        int n = wrds.length;
        for (int i = 0; i < n - 1; i++)
            for (int j = 0; j < n - 1 - i; j++)
                if (wrds[j] < wrds[j + 1]) {
                    int t = wrds[j]; wrds[j] = wrds[j + 1]; wrds[j + 1] = t;
                    String s = lines[j]; lines[j] = lines[j + 1]; lines[j + 1] = s;
                }
    }

    void print(String lines[], int wrds[]) {
        for (int i = 0; i < lines.length; i++)
            System.out.println(lines[i] + "   [words = " + wrds[i] + "]");
    }

    public static void main(String args[]) {
        Scanner sc = new Scanner(System.in);
        System.out.println("Enter the paragraph:");
        ParagraphSort ob = new ParagraphSort(sc.nextLine());
        ob.split();
        ob.sort(ob.lines, ob.wrds);
        ob.print(ob.lines, ob.wrds);
    }
}

Input

The sun rises in the east. Do you know why? It is because the earth spins from west to east! Amazing.

Output

The sum of angles is calculated as :
Let the first angle = 15 degrees 45 minutes
Let the second angle = 12 degrees 40 minutes
The sum of angles will be 28 degrees 25 minutes. (where 60 minutes = 1 degree)

Design a class Angle with the following details:
Class name : Angle
Data members/instance variables :
deg : integer to store degrees.
min : integer to store minutes.
Member functions/methods
Angle( ) : constructor to assign 0 to deg and min
void inputAngle() : to input values of deg and min.
void dispAngle() : to print the values of deg and min with proper message.
Angle sumAngle(Angle A, Angle B) : to find and return the sum of angles from objects A and B by using the above technique of adding angles

Specify the class Angle giving the details of the constructors and all the functions. You need not write the main function.

Answer

import java.util.Scanner;
class Angle {
    int deg;        // degrees
    int min;        // minutes (0 to 59)
    static Scanner sc = new Scanner(System.in);

    Angle() {
        deg = 0;
        min = 0;
    }

    void inputAngle() {
        System.out.println("Degrees: ");
        deg = sc.nextInt();
        System.out.println("Minutes: ");
        min = sc.nextInt();
    }

    void dispAngle() {
        System.out.println("Angle = " + deg + " degrees " + min + " minutes");
    }

    // returns A + B: add the minutes, carry every 60 minutes into a degree
    Angle sumAngle(Angle A, Angle B) {
        Angle S = new Angle();
        int m = A.min + B.min;
        S.min = m % 60;                    // minutes left over
        S.deg = A.deg + B.deg + m / 60;    // whole degrees plus the carry
        return S;
    }
}

class Retire extends Personal {
    int yrs;            // years of service
    double pf;          // provident fund
    double grat;        // gratuity

        grat = 0.0;

        pf = (0.02 * basicPay) * yrs;      // 2% of basic pay for each year

Q11Data Structures (queue / dequeue)[5]

Pipe is an entity which can hold at the most 50 integers. The pipe enables the user to add and remove integers. Define a class Pipe with the following details.

Class Name : Pipe
Data Members
item[] : the array to hold the integer elements
cap : stores the maximum capacity of the array
front : to point to the index of the front
rear : to point to the index of the rear.

Member Functions
Pipe(int max) : constructor to initialize the data member cap=max, front =rear=-1 and to create the integer array.
void pushrear(int v) : to add integers from the rear index if possible else display the message ("Rear full")
int popfront() : to remove the elements from front. If array is empty then return -999.
int poprear() : to remove elements from the rear. If the array is empty then return -999.
void display() : to display the array.

Specify the class Pipe giving details of the constructor and the member function void pushrear(int), int popfront(), int poprear() and void display(). The main method need not be written.

Answer

This is an input-restricted dequeue: insertion only at the rear, deletion at both ends. When the last element is removed, front and rear are reset to −1.

class Pipe {
    int item[];     // holds the integers
    int cap;        // maximum capacity
    int front;      // index of the front element (-1 when empty)
    int rear;       // index of the rear element  (-1 when empty)

    Pipe(int max) {
        cap = max;
        front = rear = -1;
        item = new int[cap];
    }

    // add at the rear
    void pushrear(int v) {
        if (rear == cap - 1) {
            System.out.println("Rear full");
            return;
        }
        if (front == -1)        // first element
            front = 0;
        item[++rear] = v;
    }

    // remove from the front; -999 if empty
    int popfront() {
        if (front == -1)
            return -999;
        int v = item[front];
        if (front == rear)      // that was the only element: reset
            front = rear = -1;
        else
            front++;
        return v;
    }

    // remove from the rear; -999 if empty
    int poprear() {
        if (rear == -1)
            return -999;
        int v = item[rear];
        if (front == rear)
            front = rear = -1;
        else
            rear--;
        return v;
    }

    void display() {
        if (front == -1) {
            System.out.println("Pipe is empty");
            return;
        }
        for (int i = front; i <= rear; i++)
            System.out.print(item[i] + " ");
        System.out.println();
    }
}

Concepts to recall

  • Empty: front = rear = −1; full (linear): rear = cap − 1.
  • Removing the only element resets both pointers.

Q12(b)Data Structures (single linked list)[2]

A linked list is formed from the objects of the class,

class ListNode
{
  float data;
  ListNode ptr;
}

Write a method Or an algorithm to compute and return the sum of all float data stored in the linked list. The method declaration is specified below:
float addList(ListNode head)

Answer

Algorithm: 1. sum ← 0, temp ← head. 2. While temp ≠ null: sum ← sum + temp.data; temp ← temp.ptr. 3. Return sum.

Method:

float addList(ListNode head) {
    float sum = 0.0f;
    ListNode temp = head;          // start at the first node
    while (temp != null) {         // until the end of the list
        sum = sum + temp.data;     // add this node's data
        temp = temp.ptr;           // move to the next node
    }
    return sum;
}

Concepts to recall

  • Traverse with a temporary reference; never move head.
  • Stop when the reference becomes null (handles an empty list too).
